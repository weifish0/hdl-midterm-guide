    • 剩餘時間從 20 開始，每 1 秒（剛好 100,000,000 週期）減 1，到 0 進入 OVER。

模擬考解答

寫完再打開。三題都通過驗證：A、B 用上面的 testbench 全部 PASS；C 在模擬中驗證過計時、得分、OVER、回到 IDLE。

A 解答：mock_A.sv

重點：A*A - B 在 16-bit 有號 context 下計算；絕對值先用 9 bits 的 diff；A >>> B[2:0] 中 A 是 signed，所以補符號位（移位量是 part-select，無號，這是我們要的）。

B 解答：mock_B.sv

重點：cnt 同時是指標；cnt[2:0] - 1 在 cnt = 8 時是 0 - 1 = 7，剛好是最上面那格。每拍先把 err、out 設成 0，後面的分支再覆寫（非阻塞指定最後一個贏）。

C 解答：mock_C.sv

重點：精準 1 秒用計數到 SEC-1 的 timer（2 的次方做不出剛好 1 秒，所以這裡不用 clock_divider）；地鼠閃爍與 OVER 閃爍直接拿提供的 clock_divider 當方波；LFSR 每拍都跑，需要時才取值。SEC、LIFE 寫成參數，模擬時可以縮小。

1. 寬度與串接

logic [3:0] a = 4'b1011;
logic [7:0] r1, r2, r3;
assign r1 = {a, a[1:0], 2'b01};
assign r2 = {2{a[3:2]}};
assign r3 = a << 5;
答案

r1 = 1011_11_01 = 8'b1011_1101；r2 = {10, 10} = 4 bits → 補成 8'b0000_1010；r3：a 先延伸到 8 bits（0000_1011）再左移 5 = 8'b0110_0000（高位掉了）。

2. 有號與無號混用

logic signed [7:0] a = -3;
logic        [7:0] b = 2;
logic signed [15:0] r1, r2;
assign r1 = a + b;
assign r2 = a + $signed(b);
答案

r1：b 無號 → 整個式子無號，a 被補 0延伸成 0x00FD（253），253 + 2 = 255。r2：全 signed，-3 + 2 = -1。

3. 計數器的值

logic [2:0] c;
always_ff @(posedge clk) begin
    if (rst)          c <= 3'd0;
    else if (c == 5)  c <= 3'd1;
    else              c <= c + 3'd2;
end
// rst 之後連續 6 個上升緣，c 依序是？
答案

0 → 2 → 4 → 6 → 0（6+2 = 8 溢位成 0）→ 2 → 4。永遠不會等於 5，那個分支是死的。

4. 狀態機

typedef enum logic [1:0] {A, B, C} st_t;
st_t s;
always_ff @(posedge clk) begin
    if (rst) s <= A;
    else case (s)
        A: if (x) s <= B;
        B: s <= x ? C : A;
        C: if (!x) s <= A;
        default: s <= A;
    endcase
end
// rst 後 x 依序為 1, 1, 1, 0, 1, 0（每拍一個），s 依序是？
答案

A →(x=1) B →(1) C →(1) C →(0) A →(1) B →(0) A。

5. 這段為什麼不能合成成你想要的？

always_ff @(posedge clk) if (tick) pos <= pos + 1;
always_ff @(posedge clk) if (rst)  pos <= 0;
答案

同一個訊號在兩個 always 區塊被指定 → multiple driver。合併成一個：if (rst) pos <= 0; else if (tick) pos <= pos + 1;
