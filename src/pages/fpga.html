方向感「往左」= index 變大（往 LD15），「往右」= index 變小（往 LD0）。題目寫 "from left to right" 的意思是 index 遞減。每次寫移動都在紙上確認一次。

XDC：把訊號名稱接到腳位

set_property PACKAGE_PIN W5 [get_ports clk]
set_property IOSTANDARD LVCMOS33 [get_ports clk]
create_clock -add -name sys_clk_pin -period 10.00 -waveform {0 5} [get_ports clk]

set_property PACKAGE_PIN U18 [get_ports rst]      ;# BTNC
set_property PACKAGE_PIN T17 [get_ports en]       ;# BTNR
set_property PACKAGE_PIN U16 [get_ports {led[0]}]
set_property PACKAGE_PIN W7  [get_ports {DISPLAY[0]}]   ;# segment a
set_property PACKAGE_PIN U2  [get_ports {DIGIT[0]}]     ;# rightmost digit

考試會給 XDC，不能改。你的 module port 名稱要跟 XDC 裡的 get_ports 一致（不要改範本的 I/O 就不會錯）。

七段顯示器

每一位數有 a–g 七個筆劃。DISPLAY = {g, f, e, d, c, b, a}，0 是亮。點下面的筆劃，看看要送什麼值：

字母：A = 0001000、E = 0000110、P = 0001100、r = 0101111、U = 1000001、- = 0111111、空白 = 1111111；S 和 5 一樣、I 和 1 一樣。

掃描（multiplexing）：四位數輪流亮

四位數共用同一組 DISPLAY 線，所以一次只能亮一位。輪流快速點亮（每位約 0.33 ms），人眼就會看到四位同時亮。

logic [16:0] refresh = '0;
always_ff @(posedge clk) refresh <= refresh + 1'b1;

always_comb begin
    case (refresh[16:15])          // 用最高兩位選擇現在亮哪一位
        2'd0: begin DIGIT = 4'b1110; ch = c0; end   // 最右
        2'd1: begin DIGIT = 4'b1101; ch = c1; end
        2'd2: begin DIGIT = 4'b1011; ch = c2; end
        default: begin DIGIT = 4'b0111; ch = c3; end   // 最左
    endcase
end
// 再用一個 case 把 ch（0~9、字母代碼）轉成 DISPLAY

完整模組在 設計模式 → 按鈕 下方的 helpers.sv。設計上的好處：你的主電路只需要決定「四個位置各顯示什麼字」（c3..c0），掃描細節全部交給它。

範本的 SevenSegment2023 年範本的 SevenSegment 吃一個 16-bit nums（每 4 bits 一位），內建代碼 10=A、11=I、12=空白、13=U、14=S、15=-。直接用範本也可以，只要記得它的代碼表；需要範本沒有的字（例如 R、P）就自己改 case。

C 題的標準架構

三年的 C 題都能套進同一張圖。考試時先把這個骨架打好，再填每個方塊的內容。

拿分的順序

  1. 骨架：貼上 btn_pulse、seven_seg、tick 產生器；宣告 enum 狀態；LED 先輸出常數。合成一次，確定能產生 bitstream。
  2. RESET 狀態（通常 5%）：初始位置的 LED、七段顯示的初始畫面。燒進板子看。
  3. 狀態轉移：按 en 進 START、再按進 PAUSE。用七段顯示器顯示狀態字母來確認。
  4. 移動：在 START 狀態用 tick 更新位置；處理邊界與環繞。
  5. 互動：碰撞、反彈、加分、set 加旗子。每做完一項就產生 bitstream、上傳一次。
  6. 結束狀態：FINISH 顯示文字、LED 閃爍。

LED 輸出 = 把各種東西 OR 起來

always_comb begin
    if (state == S_FINISH) led = blink ? 16'hAAAA : 16'h5555;
    else                   led = wall | (16'b1 << p1) | (16'b1 << p2) | apples;
end

要先想清楚的規格細節

  • 兩個物體同一個 tick 都要移動時，碰撞要用「移動後」的位置判斷，還是「移動前」？（看題目的範例圖，一格一格對）
  • 邊界是環繞（LD0 → LD15）還是反彈？
  • 同時碰到同一個目標，誰得分？（2022：AI；2023：Snake111）
  • 哪些按鈕在哪些狀態有效？（2023：mode 在 RESET 不能改；蘋果只能在 START 加）
  • 計時器 / 分數到上限之後，還會繼續變嗎？

題目沒寫清楚的情況，看 demo 影片；還是不確定就挑一個合理的做法，助教通常不會測模稜兩可的情況（2022 年題目就寫明「player_user 擴張時碰到兩面旗不用考慮」）。

Vivado 操作流程

模擬題（A、B）

  1. Create Project → RTL Project → 選板子 xc7a35tcpg236-1（Basys3）。
  2. Add Sources → Add or create design sources → 加入 exam1_A.sv（範本）。
  3. Add Sources → Add or create simulation sources → 加入 exam1_A_tb.v 和 pattern_A.dat（檔案類型選 All Files 才看得到 .dat）。
  4. Simulation Sources 裡對 testbench 按右鍵 → Set as Top。
  5. Run Simulation → Run Behavioral Simulation，看 Tcl Console 的 PASS / FAIL 訊息。
  6. 如果訊息說模擬時間不夠：Tools → Settings → Simulation → Simulation 分頁 → xsim.simulate.runtime 改大（例如 10000ns 或 -all），Apply 後重跑。
找不到 pattern 檔testbench 會印出 "Can not find pattern_A.dat"。原因幾乎都是 .dat 沒加進 simulation sources，或加到 design sources 去了。

FPGA 題（C）

  1. 加入 exam1_C.sv（design source）和 exam1_C.xdc（constraints）。
  2. Run Synthesis → 看 Messages 有沒有 Critical Warning（腳位沒接、多重驅動）。
  3. Run Implementation → Generate Bitstream。
  4. Open Hardware Manager → Open Target → Auto Connect → Program Device，選產生的 .bit。
  5. 改了程式就要從合成重跑。合成到 bitstream 大約要 2–5 分鐘，提早開始。

模擬 C 題（選用但很有用）

C 題沒有 testbench，但你可以自己寫一個很短的，把速度參數縮小，看 LED 怎麼變。比燒板子快很多。

`timescale 1ns/1ps
module tb;
    logic clk = 0, rst = 1, en = 0, set = 0, up = 0, down = 0;
    logic [15:0] sw = 0;
    logic [3:0] DIGIT; logic [6:0] DISPLAY; logic [15:0] led;
    exam1_C #(.T0(4), .DB(1)) dut (.*);     // tick 變成每 16 個週期
    always #5 clk = ~clk;

    always @(led) $display("t=%0t led=%b state=%s", $time, led, dut.state.name());

    initial begin
        repeat (5) @(posedge clk); rst = 0;
        en = 1; repeat (20) @(posedge clk); en = 0;     // 按一下 en
        repeat (500) @(posedge clk);
        $finish;
    end
endmodule
