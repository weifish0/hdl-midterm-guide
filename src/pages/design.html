設計模式：考題的零件

每一題 C 題都是這幾個零件拼起來的：狀態機、不同速度的 tick、按鈕脈衝、LED 位置運算、七段顯示。B 題則常用到數學技巧和記憶體。

FSM：把「規則」變成電路

題目寫「有 RESET、START、PAUSE 三個狀態，按 en 從 RESET 進 START……」，這就是在描述 FSM。先畫圖，再寫碼。

stateDiagram-v2
    direction LR
    [*] --> INITIAL: rst
    INITIAL --> LOAD: 下一個 clk
    LOAD --> PLAY: 16 顆 LED 全亮
    PLAY --> PLAY: end_light = 0
    PLAY --> FINAL: end_light = 1
    FINAL --> INITIAL: 閃完 3 秒

Lab 3 practice 的狀態圖。畫圖時把「轉移條件」寫在箭頭上，「這個狀態要輸出什麼」寫在旁邊。

寫法一：三段式（課堂標準）

typedef enum logic [1:0] {INITIAL, LOAD, PLAY, FINAL} state_t;
state_t state, next_state;

// (1) 狀態暫存器：只做這件事
always_ff @(posedge clk or posedge rst) begin
    if (rst) state <= INITIAL;
    else     state <= next_state;
end

// (2) 下一狀態邏輯：組合
always_comb begin
    next_state = state;                 // 預設：留在原狀態（避免 latch）
    case (state)
        INITIAL: next_state = LOAD;
        LOAD:    if (load_cnt == 16) next_state = PLAY;
        PLAY:    if (end_light)      next_state = FINAL;
        FINAL:   if (done)           next_state = INITIAL;
    endcase
end

// (3) 輸出邏輯：組合（Moore：只看狀態）
always_comb begin
    case (state)
        INITIAL: led = 16'hFFFF;
        LOAD:    led = ~(16'hFFFF << load_cnt);
        default: led = 16'h0000;
    endcase
end

寫法二：狀態與資料一起放在一個 always_ff（C 題很好用）

C 題的狀態轉換通常伴隨一堆資料更新（分數歸零、位置重設…）。把它們寫在同一個 case 裡，比拆成三段好讀：

always_ff @(posedge clk) begin
    if (rst) begin
        state <= S_RESET;
        pos   <= 4'd15;  score <= '0;      // 所有暫存器的初始值都在這裡
    end else begin
        case (state)
            S_RESET: if (en_p) state <= S_START;
            S_START: begin
                if (en_p) state <= S_PAUSE;
                if (tick) pos <= pos - 4'd1;     // 這個狀態才會動
                if (score == 4'd10) state <= S_FINISH;
            end
            S_PAUSE: if (en_p) state <= S_START;
            default: ;                           // S_FINISH
        endcase
    end
end
同一個 always 裡指定兩次？非阻塞指定時，最後一個執行到的 <= 會贏。上面 en_p 和 score == 10 同時成立時，進 FINISH。可以利用這點寫優先順序，但不要跨 always 區塊指定同一個訊號。

時間：除頻器 vs tick

Basys3 的時脈是 100 MHz（每 10 ns 一個週期）。LED 要每 0.3 秒動一次，就要「數」很多個週期。題目常寫「以 100MHz/225 的頻率移動」= 每 225 = 33,554,432 個週期（約 0.34 秒）動一次。

做法 A：除頻器當時脈（課堂範本的做法）

logic [24:0] num;
always_ff @(posedge clk) num <= num + 1'b1;
assign clk_div = num[24];          // 每 2^24 週期翻轉 -> 週期 2^25

always_ff @(posedge clk_div) pos <= pos + 1;   // 用 clk_div 當時脈

做法 B：單一時脈 + tick 脈衝（推薦）

logic [25:0] cnt;                              // 26 bits
always_ff @(posedge clk) cnt <= cnt + 1'b1;

assign tick24 = (cnt[23:0] == '1);            // 每 2^24 個週期有 1 個週期是 1
assign tick25 = (cnt[24:0] == '1);            // 每 2^25
assign tick26 = (cnt      == '1);             // 每 2^26

always_ff @(posedge clk)                       // 所有東西都用同一個 clk
    if (tick25) pos <= pos + 1;               // tick 當作 enable
為什麼推薦 tick
  • 按鈕的 one-pulse 只有 1 個 100 MHz 週期寬。如果你的 FSM 跑在 clk_div 上，那個脈衝幾乎一定會被漏掉。全部用同一個 clk 就沒有這問題。
  • 不同速度的物件（2023 年蛇的 224/225/226）要互相比較位置、判斷碰撞。如果它們在不同時脈領域，判斷會亂掉。
  • 從同一個計數器取出的 tick 會自然對齊：每次 tick26 發生時 tick25、tick24 也同時發生，正好符合 2023 題目的時序範例。

精準時間：timer（不是 2 的次方）

要剛好 1 秒（100,000,000 週期）或 0.25 秒，用計數到某個數就歸零的 timer：

module timer #(parameter integer COUNT = 100_000_000) (
    input  logic clk, rst, enable,
    output logic tick
);
    logic [31:0] num;
    always_ff @(posedge clk or posedge rst) begin
        if (rst)                   num <= '0;
        else if (!enable)          num <= '0;            // 不在該狀態時歸零
        else if (num == COUNT - 1) num <= '0;
        else                       num <= num + 1'b1;
    end
    assign tick = enable && (num == COUNT - 1);
endmodule

1 秒100,000,00027 bits（227 ≈ 1.34 億）
0.5 秒50,000,00026 bits
0.25 秒25,000,00025 bits
226 週期67,108,864（≈0.67 秒，題目說「約 1 秒」那種）26 bits
225 週期33,554,432（≈0.34 秒）25 bits

按鈕：debounce + one-pulse

按一次按鈕，人手按住大約 0.1–0.3 秒 = 一千萬個週期以上。如果直接用 if (btn) mode <= mode + 1，按一下 mode 就加了一千萬次。而且機械按鈕剛按下時會彈跳（0/1 快速抖動幾毫秒）。

module debounce #(parameter n = 4) (
    input  logic clk, pb,
    output logic pb_debounced
);
    logic [n-1:0] shift_reg;
    always_ff @(posedge clk)
        shift_reg <= {shift_reg[n-2:0], pb};
    assign pb_debounced = &shift_reg;   // 全 1
endmodule
module one_pulse (
    input  logic clk, pb_in,
    output logic pb_out
);
    logic pb_in_delay;
    always_ff @(posedge clk) begin
        pb_out      <= pb_in & ~pb_in_delay;
        pb_in_delay <= pb_in;
    end
endmodule

課堂範本的 debounce 如果直接接 100 MHz，4 個 flip-flop 只取樣了 40 ns，根本濾不掉彈跳。範本的做法是把 debounce 接到除頻後的時脈（例如 216），但這樣 one-pulse 也只能在慢時脈下用。

下面這個版本把兩者合在一起、全部跑在 100 MHz：每 216 週期取樣一次按鈕（約 0.65 ms），連續 4 次是 1 才算穩定，然後輸出一個 100 MHz 週期寬的脈衝。本站所有 C 題解答都用它。

reset 按鈕需要 debounce 嗎？不太需要。reset 只要「有被按到」就好，多 reset 幾次沒差。考題範本也是直接用 rst。

LFSR：用移位暫存器做偽亂數

Linear Feedback Shift Register：每一拍往左移一位，最右邊補上「某幾個 bit 的 XOR」。選對 tap 的話，n bits 會跑遍 2n−1 種非零狀態再重複。Lab 4 practice 和 Lab 4 advanced（蛇的食物位置）都用到。

logic [3:0] lfsr;
always_ff @(posedge clk or posedge rst) begin
    if (rst)       lfsr <= 4'b0001;
    else if (adv)  lfsr <= {lfsr[2:0], lfsr[3] ^ lfsr[0]};
end
步驟lfsrlfsr[1:0]（方向）

1001111 Up
2011111 Up
3111111 Up
4111010 Down
5110101 Right
…共 15 個狀態後回到 0001

想要「每一拍都換」的亂數（例如在玩家按鍵的瞬間取值），就讓 LFSR 每個 clk 都跑（free-running），按鍵時讀取它的值。

記憶體：陣列 + 讀寫埠

Lab 5 是這次考試新加的範圍。logic [3:0] memory [0:7]; 就是 8 個 4-bit 的格子。重點在讀寫的時序與規則。

四個規則

  1. 位址對應：idx = addr[2:0] ^ addr[6:4] ^ addr[3:1]。比較讀寫是否同一格要比對應後的 index，不是原始位址（5A 和 03 都對到 index 2）。
  2. valid bit：每格一個 bit，第一次寫入才設 1。cnt_valid 只在「寫入原本 invalid 的格子」時 +1。
  3. 同步讀：re = 1 時，下一個上升緣 dout 變成該格內容（invalid 則 0）；re = 0 則 dout 變 0。
  4. write-first：同一拍又讀又寫同一格，dout 要給新寫入的值。因為非阻塞指定時 memory[ri] 還是舊值，所以要自己加旁路。

指標（pointer）：用記憶體做 FIFO / Stack

Lab 4 advanced 的蛇身體用 FIFO 存：head 指標指向最新的節點、tail 指標指向最舊的。深度取 2 的次方（32），指標用 5 bits 就會自然繞回 0。

logic [4:0] body [0:31];
logic [4:0] head, tail;               // 5-bit 指標：31 + 1 = 0，自動環狀

always_ff @(posedge clk) begin
    if (step) begin
        head       <= head + 1'b1;    // push 新頭
        body[head + 1'b1] <= new_node;
        if (!ate)  tail <= tail + 1'b1;   // 沒吃到才 pop 尾巴（吃到就變長）
    end
end
// 長度 = head - tail + 1（5-bit 減法自動處理繞回）

模擬考 B 題就是一個用記憶體做的 stack（LIFO），練習這種「指標 + 陣列 + 邊界檢查」。

不用 / 和 % 的技巧

B 題常禁止除法和取餘數（用了只拿一半分數），因為它們合成出來的電路很大。2 的次方都可以用位元操作取代。

想算寫成說明
x % 8x[2:0]對 2k 取餘數 = 取最低 k 位
x % 4 == 0x[1:0] == 2'b00
S % 8 == i % 8S[2:0] == i[2:0]2021、2022 B 題
x 是奇數x[0]
x / 4（無號）x >> 2有號用 >>>，注意負數是向下取整
x * 3(x << 1) + x* 其實沒被禁止，但這樣寫很直覺
x * 6(x << 2) + (x << 1)2022 B 題
(S/2) * 3(S >> 1) + ((S >> 1) << 1)2022 B 題（S 為偶數）
c >> (i % 4)c >> i[1:0]移位量可以是變數（合成成 barrel shifter）

顯示兩位數：十位與個位

七段顯示器一次顯示一個 0–9 的數字，所以分數 13 要拆成 1 和 3。數值範圍小時，用比較最簡單：

assign tens = (score >= 10) ? 1 : 0;
assign ones = (score >= 10) ? score - 10 : score;
assign tens = score / 10;      // 除以常數，Vivado 會合成成乘法 + 移位
assign ones = score % 10;

另一個做法是直接用兩個 BCD 計數器（個位到 9 進位到十位），計時器很常這樣做：

always_ff @(posedge clk) begin
    if (rst) begin ones <= 0; tens <= 0; end
    else if (sec_tick) begin
        if (ones == 4'd9) begin ones <= 0; tens <= tens + 1; end
        else               ones <= ones + 1;
    end
end

LED 位置運算

logic [3:0]  pos;                      // 0~15
logic [15:0] mask;
assign mask = 16'b1 << pos;            // one-hot：只有 pos 那顆亮

// 環狀移動（LD0 再往右 = LD15）：4-bit 自動繞回
pos <= pos - 4'd1;                      // 0 - 1 = 15 ✔

// 3 格長的物體，右端在 r：
assign body = 16'b111 << r;

// 環狀旋轉（物體跨過邊界）
assign rot = (base << k) | (base >> (16 - k));

// 碰撞：兩個遮罩有重疊
assign hit = |(mask_a & mask_b);
// 吃到東西
assign eat = |(apple & mask_snake);
apple <= apple & ~mask_snake;           // 把吃掉的清掉
