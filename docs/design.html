設計模式：考題的零件

每一題 C 題都是這幾個零件拼起來的：狀態機、不同速度的 tick、按鈕脈衝、LED 位置運算、七段顯示。B 題則常用到數學技巧和記憶體。

FSM：把「規則」變成電路

題目寫「有 RESET、START、PAUSE 三個狀態，按 en 從 RESET 進 START……」，這就是在描述 FSM。先畫圖，再寫碼。

stateDiagram-v2
    direction LR
    [*] --> INITIAL: rst
    INITIAL --> LOAD: 下一個 clk
    LOAD --> PLAY: 16 顆 LED 全亮
    PLAY --> PLAY: end_light = 0
    PLAY --> FINAL: end_light = 1
    FINAL --> INITIAL: 閃完 3 秒

Lab 3 practice 的狀態圖。畫圖時把「轉移條件」寫在箭頭上，「這個狀態要輸出什麼」寫在旁邊。

寫法一：三段式（課堂標準）

typedef enum logic [1:0] {INITIAL, LOAD, PLAY, FINAL} state_t;
state_t state, next_state;

// (1) 狀態暫存器：只做這件事
always_ff @(posedge clk or posedge rst) begin
    if (rst) state <= INITIAL;
    else     state <= next_state;
end

// (2) 下一狀態邏輯：組合
always_comb begin
    next_state = state;                 // 預設：留在原狀態（避免 latch）
    case (state)
        INITIAL: next_state = LOAD;
        LOAD:    if (load_cnt == 16) next_state = PLAY;
        PLAY:    if (end_light)      next_state = FINAL;
        FINAL:   if (done)           next_state = INITIAL;
    endcase
end

// (3) 輸出邏輯：組合（Moore：只看狀態）
always_comb begin
    case (state)
        INITIAL: led = 16'hFFFF;
        LOAD:    led = ~(16'hFFFF << load_cnt);
        default: led = 16'h0000;
    endcase
end

寫法二：狀態與資料一起放在一個 always_ff（C 題很好用）

C 題的狀態轉換通常伴隨一堆資料更新（分數歸零、位置重設…）。把它們寫在同一個 case 裡，比拆成三段好讀：

always_ff @(posedge clk) begin
    if (rst) begin
        state <= S_RESET;
        pos   <= 4'd15;  score <= '0;      // 所有暫存器的初始值都在這裡
    end else begin
        case (state)
            S_RESET: if (en_p) state <= S_START;
            S_START: begin
                if (en_p) state <= S_PAUSE;
                if (tick) pos <= pos - 4'd1;     // 這個狀態才會動
                if (score == 4'd10) state <= S_FINISH;
            end
            S_PAUSE: if (en_p) state <= S_START;
            default: ;                           // S_FINISH
        endcase
    end
end
同一個 always 裡指定兩次？非阻塞指定時，最後一個執行到的 <= 會贏。上面 en_p 和 score == 10 同時成立時，進 FINISH。可以利用這點寫優先順序，但不要跨 always 區塊指定同一個訊號。

時間：除頻器 vs tick

Basys3 的時脈是 100 MHz（每 10 ns 一個週期）。LED 要每 0.3 秒動一次，就要「數」很多個週期。題目常寫「以 100MHz/225 的頻率移動」= 每 225 = 33,554,432 個週期（約 0.34 秒）動一次。

做法 A：clk_div 直接當時脈（課堂範本的做法）

logic clk_25;
clock_divider #(.n(25)) u_cd25 (.clk(clk), .clk_div(clk_25));   // clk_div = num[24]，週期 2^25

always_ff @(posedge clk_25) pos <= pos + 1;   // 用 clk_25 當時脈

做法 B：clk_div 轉成 tick，所有邏輯只用 clk（推薦）

還是用考試給的 clock_divider，但不拿它的輸出當時脈，而是用同樣考試給的 one_pulse 把它變成「每 2n 週期出現一次、寬度一個 clk」的脈衝。概念跟按鈕完全一樣：把 clk_div 想成一顆每 2n 週期被按一次的按鈕。

logic cd25, tick25;
clock_divider #(.n(25)) u_cd25 (.clk(clk), .clk_div(cd25));
one_pulse     u_t25    (.clk(clk), .pb_in(~cd25), .pb_out(tick25));   // clk_div 由 1 掉到 0 的那一拍

always_ff @(posedge clk)                       // 所有東西都用同一個 clk
    if (tick25) pos <= pos + 1;               // tick 當作 enable

為什麼用 ~cd25（抓下降緣）？clk_div 從 1 掉到 0 的瞬間，就是計數器從全 1 繞回 0 的時候，也就是 2n 的整數倍。所以 224、225、226 三個 tick 會自動對齊：每次 226 的 tick 出現，另外兩個也同時出現，正好符合 2023 年題目「兩條蛇同時被觸發」的時序範例。

不用提供的模組也可以：自己寫一個計數器，tick = (cnt[24:0] == '1)。效果一樣。

為什麼推薦 tick
  • 按鈕的 one-pulse 只有 1 個 100 MHz 週期寬。如果你的 FSM 跑在 clk_div 上，那個脈衝幾乎一定會被漏掉。全部用同一個 clk 就沒有這問題。
  • 不同速度的物件（2023 年蛇的 224/225/226）要互相比較位置、判斷碰撞。如果它們在不同時脈領域，判斷會亂掉。
  • 從同一個計數器取出的 tick 會自然對齊：每次 tick26 發生時 tick25、tick24 也同時發生，正好符合 2023 題目的時序範例。

精準時間：timer（不是 2 的次方）

要剛好 1 秒（100,000,000 週期）或 0.25 秒，用計數到某個數就歸零的 timer：

module timer #(parameter integer COUNT = 100_000_000) (
    input  logic clk, rst, enable,
    output logic tick
);
    logic [31:0] num;
    always_ff @(posedge clk or posedge rst) begin
        if (rst)                   num <= '0;
        else if (!enable)          num <= '0;            // 不在該狀態時歸零
        else if (num == COUNT - 1) num <= '0;
        else                       num <= num + 1'b1;
    end
    assign tick = enable && (num == COUNT - 1);
endmodule

1 秒100,000,00027 bits（227 ≈ 1.34 億）
0.5 秒50,000,00026 bits
0.25 秒25,000,00025 bits
226 週期67,108,864（≈0.67 秒，題目說「約 1 秒」那種）26 bits
225 週期33,554,432（≈0.34 秒）25 bits

模擬時把時間縮短

在模擬器跑 225 個週期要很久。把計數寬度寫成參數，testbench 裡覆寫成小數字：

module exam1_C #(parameter int T0 = 24) ( ... );
    clock_divider #(.n(T0))   u_cd0 (.clk(clk), .clk_div(cd0));   // 2^T0
    clock_divider #(.n(T0+1)) u_cd1 (.clk(clk), .clk_div(cd1));   // 2^(T0+1)
...
// testbench：exam1_C #(.T0(4)) dut (.*);   -> 每 16 個週期就動一次
模擬提供的模組時clock_divider 沒有 reset，計數器在模擬裡一開始是 X，X + 1 永遠是 X。上板沒問題（FPGA 上電是 0），但 testbench 要在 0 時刻把它設成 0：initial begin force dut.u_cd0.num = 0; #1 release dut.u_cd0.num; end。

按鈕：debounce + one-pulse

按一次按鈕，人手按住大約 0.1–0.3 秒 = 一千萬個週期以上。如果直接用 if (btn) mode <= mode + 1，按一下 mode 就加了一千萬次。而且機械按鈕剛按下時會彈跳（0/1 快速抖動幾毫秒）。

考試會直接給你clock_divider、debounce、onepulse（SV 版叫 one_pulse）、SevenSegment 和 XDC。不用自己寫，重點是知道怎麼接。下面是 Lab 4 advanced 附的 SystemVerilog 版本，原封不動。
// ===================================================================
// Course-provided modules (SystemVerilog versions from Lab 4 advanced).
// The exam gives you: clock_divider, debounce, onepulse (one_pulse),
// SevenSegment and the XDC file. Copied here VERBATIM for reference.
// ===================================================================

module clock_divider #(
    parameter n = 27 // 2^27 / 100M Hz = 1.34s
)(
    input logic  clk,
    output logic clk_div  
);

    logic [n-1:0] num;
    logic [n-1:0] next_num;

    always_ff @(posedge clk) begin
        num <= next_num;
    end

    assign next_num = num + 1'b1;
    assign clk_div = num[n-1];
endmodule


module debounce #(
    parameter n = 8
)(
    input logic clk,
    input logic pb,
    output logic pb_debounced
);

    logic [n-1:0] shift_reg;

    always_ff @(posedge clk) begin
        shift_reg[n-1:1] <= shift_reg[n-2:0];
        shift_reg[0] <= pb;
    end

    assign pb_debounced = &shift_reg;
endmodule


module one_pulse (
    input logic clk,
    input logic pb_in,
    output logic pb_out
);

	logic pb_in_delay;

	always_ff @(posedge clk) begin
		pb_out <= (pb_in & ~pb_in_delay);
		pb_in_delay <= pb_in;
	end
endmodule


module SevenSegment(
	output logic [6:0] display,
	output logic [3:0] digit,
	input logic [15:0] nums,
	input logic rst,
	input logic clk
);
    
    logic [15:0] clk_divider;
    logic [3:0] display_num;
    
    always_ff @(posedge clk or posedge rst) begin
    	if (rst) begin
    		clk_divider <= 16'd0;
    	end else begin
    		clk_divider <= clk_divider + 16'd1;
    	end
    end
    
    always_ff @(posedge clk_divider[15] or posedge rst) begin
    	if (rst) begin
    		display_num <= 4'b0000;
    		digit <= 4'b1111;
    	end else begin
    		case (digit)
    			4'b1110 : begin
					display_num <= nums[7:4];
					digit <= 4'b1101;
    			end
    			4'b1101 : begin
					display_num <= nums[11:8];
					digit <= 4'b1011;
				end
    			4'b1011 : begin
					display_num <= nums[15:12];
					digit <= 4'b0111;
				end
    			4'b0111 : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end
    			default : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end				
    		endcase
    	end
    end
    
    always_comb begin
    	case (display_num)
    		4'd0: display = 7'b1000000;
            4'd1: display = 7'b1111001;
            4'd2: display = 7'b0100100;
            4'd3: display = 7'b0110000;
            4'd4: display = 7'b0011001;
            4'd5: display = 7'b0010010;
            4'd6: display = 7'b0000010;
            4'd7: display = 7'b1111000;
            4'd8: display = 7'b0000000;

			default : display = 7'b1111111;

怎麼接：debounce 用慢時脈，one_pulse 用 100 MHz

debounce 是 8 個 flip-flop 的移位暫存器，8 個取樣全是 1 才輸出 1。如果直接接 100 MHz，8 個取樣只涵蓋 80 ns，按鈕彈跳是好幾毫秒，幾乎濾不掉（你的 Lab 4 practice 就是這樣接的，大多數時候也能動，偶爾會一按跳兩下）。

比較穩的接法：用 clock_divider #(.n(16)) 做一個 216 週期（約 0.65 ms）的慢時脈給 debounce，8 個取樣就涵蓋約 5 ms；one_pulse 則接 100 MHz 的 clk，這樣每按一次只會產生一個 clk 週期的脈衝，主電路（也跑在 clk 上）一定看得到。

logic clk_db;
clock_divider #(.n(16)) u_cd_db (.clk(clk), .clk_div(clk_db));   // 一個就夠，所有按鈕共用

logic en_d, en_p;
debounce  u_db_en (.clk(clk_db), .pb(en),   .pb_debounced(en_d));  // 慢時脈取樣
one_pulse u_op_en (.clk(clk),    .pb_in(en_d), .pb_out(en_p));    // 100 MHz 單脈衝

always_ff @(posedge clk)
    if (en_p) state <= S_START;      // en_p 只有一個 clk 寬：按一次只觸發一次
2023 範本是 Verilog 版名稱和 port 順序不一樣：debounce(pb_debounced, pb, clk)、onepulse(pb_debounced, clk, pb_1pulse)。考試拿到哪個版本就照它的 port 名稱接，用名稱連接（.pb(en)）就不怕順序。
reset 按鈕需要 debounce 嗎？不太需要。reset 只要「有被按到」就好，多 reset 幾次沒差。考題範本也是直接用 rst。

LFSR：用移位暫存器做偽亂數

Linear Feedback Shift Register：每一拍往左移一位，最右邊補上「某幾個 bit 的 XOR」。選對 tap 的話，n bits 會跑遍 2n−1 種非零狀態再重複。Lab 4 practice 和 Lab 4 advanced（蛇的食物位置）都用到。

logic [3:0] lfsr;
always_ff @(posedge clk or posedge rst) begin
    if (rst)       lfsr <= 4'b0001;
    else if (adv)  lfsr <= {lfsr[2:0], lfsr[3] ^ lfsr[0]};
end
步驟lfsrlfsr[1:0]（方向）
0000101 Right
1001111 Up
2011111 Up
3111111 Up
4111010 Down
5110101 Right
…共 15 個狀態後回到 0001

想要「每一拍都換」的亂數（例如在玩家按鍵的瞬間取值），就讓 LFSR 每個 clk 都跑（free-running），按鍵時讀取它的值。

記憶體：陣列 + 讀寫埠

Lab 5 是這次考試新加的範圍。logic [3:0] memory [0:7]; 就是 8 個 4-bit 的格子。重點在讀寫的時序與規則。

四個規則

  1. 位址對應：idx = addr[2:0] ^ addr[6:4] ^ addr[3:1]。比較讀寫是否同一格要比對應後的 index，不是原始位址（5A 和 03 都對到 index 2）。
  2. valid bit：每格一個 bit，第一次寫入才設 1。cnt_valid 只在「寫入原本 invalid 的格子」時 +1。
  3. 同步讀：re = 1 時，下一個上升緣 dout 變成該格內容（invalid 則 0）；re = 0 則 dout 變 0。
  4. write-first：同一拍又讀又寫同一格，dout 要給新寫入的值。因為非阻塞指定時 memory[ri] 還是舊值，所以要自己加旁路。
// Lab 5 Practice — 8 x 4-bit RAM, 1 read + 1 write port, write-first, valid bits
`timescale 1ns/1ps
module lab5_practice (
    input  logic       clk,
    input  logic       rst,        // synchronous
    input  logic       we,
    input  logic [6:0] w_addr,
    input  logic [3:0] din,
    input  logic       re,
    input  logic [6:0] r_addr,
    output logic [3:0] dout,
    output logic [3:0] cnt_valid
);
    logic [3:0] memory [0:7];
    logic [7:0] valid;
    logic [2:0] wi, ri;            // mapped 3-bit indices

    // XOR folding: 7-bit address -> 3-bit index
    assign wi = w_addr[2:0] ^ w_addr[6:4] ^ w_addr[3:1];
    assign ri = r_addr[2:0] ^ r_addr[6:4] ^ r_addr[3:1];

    always_ff @(posedge clk) begin
        if (rst) begin
            for (int k = 0; k < 8; k++) memory[k] <= 4'd0;
            valid     <= 8'd0;
            cnt_valid <= 4'd0;
            dout      <= 4'd0;
        end else begin
            // ---- write port ----
            if (we) begin
                memory[wi] <= din;
                valid[wi]  <= 1'b1;
                if (!valid[wi]) cnt_valid <= cnt_valid + 4'd1;   // first write only
            end
            // ---- read port (registered) ----
            if (!re)                    dout <= 4'd0;
            else if (we && wi == ri)    dout <= din;             // write-first bypass
            else if (valid[ri])         dout <= memory[ri];
            else                        dout <= 4'd0;
        end
    end
endmodule

指標（pointer）：用記憶體做 FIFO / Stack

Lab 4 advanced 的蛇身體用 FIFO 存：head 指標指向最新的節點、tail 指標指向最舊的。深度取 2 的次方（32），指標用 5 bits 就會自然繞回 0。

logic [4:0] body [0:31];
logic [4:0] head, tail;               // 5-bit 指標：31 + 1 = 0，自動環狀

always_ff @(posedge clk) begin
    if (step) begin
        head       <= head + 1'b1;    // push 新頭
        body[head + 1'b1] <= new_node;
        if (!ate)  tail <= tail + 1'b1;   // 沒吃到才 pop 尾巴（吃到就變長）
    end
end
// 長度 = head - tail + 1（5-bit 減法自動處理繞回）

模擬考 B 題就是一個用記憶體做的 stack（LIFO），練習這種「指標 + 陣列 + 邊界檢查」。

不用 / 和 % 的技巧

B 題常禁止除法和取餘數（用了只拿一半分數），因為它們合成出來的電路很大。2 的次方都可以用位元操作取代。

想算寫成說明
x % 8x[2:0]對 2k 取餘數 = 取最低 k 位
x % 4 == 0x[1:0] == 2'b00
S % 8 == i % 8S[2:0] == i[2:0]2021、2022 B 題
x 是奇數x[0]
x / 4（無號）x >> 2有號用 >>>，注意負數是向下取整
x * 3(x << 1) + x* 其實沒被禁止，但這樣寫很直覺
x * 6(x << 2) + (x << 1)2022 B 題
(S/2) * 3(S >> 1) + ((S >> 1) << 1)2022 B 題（S 為偶數）
c >> (i % 4)c >> i[1:0]移位量可以是變數（合成成 barrel shifter）

顯示兩位數：十位與個位

七段顯示器一次顯示一個 0–9 的數字，所以分數 13 要拆成 1 和 3。數值範圍小時，用比較最簡單：

assign tens = (score >= 10) ? 1 : 0;
assign ones = (score >= 10) ? score - 10 : score;
assign tens = score / 10;      // 除以常數，Vivado 會合成成乘法 + 移位
assign ones = score % 10;

另一個做法是直接用兩個 BCD 計數器（個位到 9 進位到十位），計時器很常這樣做：

always_ff @(posedge clk) begin
    if (rst) begin ones <= 0; tens <= 0; end
    else if (sec_tick) begin
        if (ones == 4'd9) begin ones <= 0; tens <= tens + 1; end
        else               ones <= ones + 1;
    end
end

LED 位置運算

logic [3:0]  pos;                      // 0~15
logic [15:0] mask;
assign mask = 16'b1 << pos;            // one-hot：只有 pos 那顆亮

// 環狀移動（LD0 再往右 = LD15）：4-bit 自動繞回

// 3 格長的物體，右端在 r：
assign body = 16'b111 << r;

// 環狀旋轉（物體跨過邊界）
assign rot = (base << k) | (base >> (16 - k));

// 碰撞：兩個遮罩有重疊
assign hit = |(mask_a & mask_b);
// 吃到東西
assign eat = |(apple & mask_snake);
apple <= apple & ~mask_snake;           // 把吃掉的清掉
