SystemVerilog 語法

寫硬體不是寫程式。每一行描述的是「一塊電路」，所有電路同時在運作。先建立這個觀念，下面的規則就都說得通。

模組（module）：一顆晶片

一個 module 就像一顆有接腳的 IC。input／output 是接腳，裡面宣告的訊號是內部的線或暫存器。

`timescale 1ns/1ps            // 模擬時間單位 / 精度（只影響模擬）
module adder8 (
    input  logic [7:0] a,      // [7:0] = 8 bits, bit 7 是 MSB
    input  logic [7:0] b,
    output logic [8:0] sum     // 9 bits 才裝得下進位
);
    assign sum = a + b;        // 連續指定：一條永遠成立的「接線」
endmodule

logic：SystemVerilog 只需要這一種型別

Verilog 要分 wire（被 assign 驅動）和 reg（在 always 裡被指定）。SystemVerilog 的 logic 兩種都能用，工具會依你怎麼驅動它決定變成線還是 flip-flop。

注意reg 不代表一定是暫存器！在 always_comb 裡指定的 logic 合成出來是組合邏輯。真正決定「是不是 flip-flop」的是：它是不是在時脈邊緣被指定。

唯一的限制：一個 logic 只能有一個驅動來源（一條 assign 或一個 always 區塊）。兩個 always 都寫同一個訊號會報 multiple driver 錯誤。

向量、索引、陣列

logic [15:0] led;          // 16-bit 向量，led[15] 是最左邊的 LED
logic        bit0;          // 1 bit
logic [3:0]  nib;

assign nib  = led[7:4];     // 取一段（part-select）
assign bit0 = led[0];
// led[i] 的 i 可以是變數（會合成成多工器）

logic [3:0] memory [0:7];   // 陣列：8 個 entry，每個 4 bits（Lab 5 的 RAM）
// memory[2]      -> 第 2 個 entry（4 bits）
// memory[2][3]   -> 第 2 個 entry 的 bit 3

常數（literal）怎麼寫

寫法意思備註

parameter 與 localparam

module counter #(parameter int N = 8) (   // 可以從外面覆寫
    input  logic clk, rst,
    output logic [N-1:0] q
);
    localparam logic [N-1:0] MAX = '1;    // 只在模組內用，不能覆寫
    always_ff @(posedge clk)
        if (rst) q <= '0; else q <= q + 1'b1;
endmodule

counter #(.N(26)) u_cnt (.clk(clk), .rst(rst), .q(cnt26));   // 覆寫成 26 bits

typedef enum：狀態機一定要用

typedef enum logic [1:0] {S_RESET, S_START, S_PAUSE} state_t;   // 編碼 0, 1, 2
state_t state, next_state;

// 模擬波形上會直接顯示 S_START，而不是 2'b01，很好除錯
if (state == S_START) ...

運算子總表

類別運算子例子（a = 4'b1100, b = 4'b1010）
位元運算& | ^ ~ ~^a & b = 4'b1000，a ^ b = 4'b0110，~(a|b) = 4'b0001（nor）
縮減（reduction）&a |a ^a&a = 0（全 1 才 1）、|a = 1、^a = 0（奇數個 1 才 1，就是 parity）
邏輯&& || !結果 1 bit：(a != 0) && (b != 0)
算術+ - * / % **/ % 合成成很大的電路，考試常禁用
比較== != < <= > >=有號／無號由運算元決定（見下一頁）
邏輯移位<< >>補 0：a >> 1 = 4'b0110
算術移位<<< >>>右移補符號位（只有運算元是 signed 才會）
串接{a, b}{a, b} = 8'b1100_1010
複製{n{x}}{4{1'b1}} = 4'b1111、{{8{x[7]}}, x} 手動符號延伸
條件c ? x : y就是一個 2 選 1 多工器

位元寬度規則（最常被扣分的地方）

Verilog/SV 的運算不是「各算各的」，而是先看整個式子（包含等號左邊）裡最寬的是多寬，所有運算元都先擴展到那個寬度再算。這叫 context-determined。

logic [7:0]  a = 8'd200, b = 8'd100;
logic [7:0]  s8;
logic [8:0]  s9;

assign s8 = a + b;    // 300 裝不下 8 bits -> 44 （溢位，進位被丟掉）
assign s9 = a + b;    // 左邊 9 bits，a、b 先擴成 9 bits 再加 -> 300 ✔

// 陷阱：比較式裡的加法
if (a + b > 8'd250)   // 比較運算元會擴到兩邊最寬的寬度 = 8 bits -> 溢位！
if (9'(a + b) > 250)  // 用 9'( ) 強制寬度（SV 的 cast）
口訣
  • 加法結果多 1 bit；乘法結果寬度是兩者相加（8×8 → 16）。
  • 串接 { } 裡面的東西不會被擴展，每段保持自己的寬度。
  • 寬的東西指定給窄的變數：直接砍掉高位元（Vivado 只給 warning，不會報錯）。

移位的細節

logic [7:0] x = 8'b1001_0110;
x << 2      // 8'b0101_1000（高位被丟掉）
x >> 2      // 8'b0010_0101
x >>> 2     // x 是無號 -> 跟 >> 一樣補 0！

logic signed [7:0] y = -8'sd8;   // 8'b1111_1000
y >>> 1     // 8'b1111_1100 = -4  ✔ 補符號位
y >> 1      // 8'b0111_1100 = 124 ✘ 邏輯右移不管正負

// 用移位取代乘除（2 的次方）
x << 3      // x * 8
x >> 1      // x / 2（無號，無條件捨去）
(x << 1) + x    // x * 3

有號數：A 題每年都考

電路裡只有 0 和 1。8'b1111_1111 是 255 還是 -1，完全看你怎麼解讀。有號數用二補數（two's complement）：最高位元是符號位，-x = ~x + 1。

8-bit 二進位無號有號
0000_010155
0111_1111127127（最大）
1000_0000128-128（最小）
1111_1011251-5
1111_1111255-1

符號延伸（sign extension）

把 8-bit 有號數放進 16 bits，要把符號位往左複製，值才不變：-5 = 1111_1011 → 1111_1111_1111_1011。題目說 "with sign extension" 就是這個意思。

規則：整個式子「全部都是 signed」才會做有號運算

input  logic signed [7:0]  A, B;     // 宣告成 signed
output logic signed [15:0] out;

out = A * B;            // ✔ 全部 signed：A、B 先符號延伸到 16 bits 再乘
out = A * B + 3;        // ✔ 3 是 32-bit signed 整數，還是全 signed
out = A * B + 16'd3;    // ✘ 16'd3 是 unsigned -> 整個式子變無號！A、B 補 0
out = A * B + 16'sd3;   // ✔
out = A + B[3:0];       // ✘ part-select（B[3:0]）永遠是 unsigned
out = {A, B};           // 串接結果永遠是 unsigned（但只是放 bits，沒差）

// 補救：$signed() / $unsigned()
out = A + $signed({1'b0, B[3:0]});
2022 年的陷阱：A * (-B)

B = -128 時，8-bit 的 -B 還是 -128（溢位）。但 out = A * (-B); 這樣寫是對的，因為 -B 也在 16-bit 的 context 裡算：B 先延伸成 16 bits 再取負 = +128。錯的寫法是先存進 8-bit 變數：logic signed [7:0] nb = -B;。

算術右移 vs 除法

2023 年題目要求不用 / 實作 A/4 > B，答案是 (A >>> 2) > B。兩者對負數其實有一點差別：

AA / 4（向 0 捨去）A >>> 2（向下取整）
1333
-13-3-4
-8-2-2

題目提示「Be careful with the sign bit and the shifter」，而且官方 pattern 兩種寫法都會過（已實測 201 筆）。考試時照題目提示用 >>>，並確認 A 有宣告成 signed。

常見寫法速記

// 1) 絕對值
abs = x[7] ? -x : x;                   // x 為 signed，結果要多 1 bit 才裝得下 128

// 2) 比較大小直接用（兩邊都 signed 才是有號比較）
out = (A < B) ? -16'sd1 : 16'sd1;

// 3) 溢位偵測：兩個同號相加，結果變號 = 溢位
logic signed [8:0] s = A + B;           // 多 1 bit 就不會溢位
sat = (s > 127) ? 127 : (s < -128) ? -128 : s[7:0];   // 飽和（Lab 2 practice）

// 4) 手動符號延伸
ext = {{8{A[7]}}, A};                   // 8 -> 16 bits

組合邏輯：輸出只跟「現在的輸入」有關

沒有記憶。輸入一變，輸出（經過一點延遲）就跟著變。兩種寫法：

assign y = sel ? b : a;
assign parity = ^data;
assign led = sw | wall;

簡單的一行運算用 assign。

always_comb begin
    case (ctrl)
        2'b00:   y = a + b;
        2'b01:   y = a - b;
        default: y = '0;
    endcase
end

需要 if/case 時用 always_comb，裡面用 =（阻塞）。

Latch：組合邏輯最常見的 bug

如果某個情況下沒有指定輸出，電路必須「記住上一個值」，工具就會生出 latch。Latch 在 FPGA 上會造成時序問題，考試 C 題可能因此行為怪異。

always_comb begin
    if (en) y = a;
    // en = 0 時 y 沒被指定！
end
always_comb begin
    y = '0;            // 先給預設值
    if (en) y = a;
end
避免 latch 的兩個習慣
  1. always_comb 第一行先給所有輸出預設值。
  2. case 一定寫 default。
SystemVerilog 的 always_comb 在產生 latch 時會給 warning，比 Verilog 的 always @(*) 容易抓。

case 的寫法

always_comb begin
    case (sel)
        2'b00:          y = a;
        2'b01, 2'b10:   y = b;          // 多個值同一個分支
        default:        y = c;
    endcase
end

// if-else 串會有優先順序（先判斷的贏）
always_comb begin
    if      (btn_rst)  next = S_RESET;   // 最高優先
    else if (btn_go)   next = S_START;
    else               next = state;
end

for 迴圈 = 複製電路

在 always_comb 裡的 for 不是「跑很多次」，而是把電路攤開複製 N 份。迴圈次數必須是常數。

always_comb begin
    ones = '0;
    for (int i = 0; i < 16; i++)
        ones = ones + led[i];      // 合成出 16 個加法器串起來
end

循序邏輯：時脈邊緣才更新

Flip-flop（正反器）只在 clk 上升緣（posedge）把輸入「拍照」存起來，其他時間保持不變。所有計數器、狀態機、暫存器都是它。

always_ff @(posedge clk) begin
    if (rst) q <= '0;      // 同步 reset：只在 clk 上升緣才看 rst
    else     q <= d;       // 循序邏輯一律用 <=（非阻塞）
end

同步 reset vs 非同步 reset

考試 A、B 題每年都寫「reset synchronously」，Lab 3/4 則用非同步。差別只在敏感清單：

always_ff @(posedge clk) begin
    if (rst) q <= '0;
    else     q <= d;
end
always_ff @(posedge clk or posedge rst) begin
    if (rst) q <= '0;
    else     q <= d;
end

阻塞 = vs 非阻塞 <=

非阻塞：右邊全部用「邊緣之前的舊值」算完，再一起更新。這才符合真實硬體（所有 flip-flop 同時拍照）。

always_ff @(posedge clk) begin
    a <= b;
    b <= a;    // 用的是舊的 a
end
always_ff @(posedge clk) begin
    a = b;
    b = a;     // a 已經被改成 b 了
end
規則，不要例外
  • always_ff 裡只用 <=。
  • always_comb 裡只用 =。
  • 同一個訊號只在一個 always 區塊裡指定。

「晚一拍」：暫存輸出的時序

A、B 題都要求「在輸出前加一級 flip-flop」。意思是：第 N 個週期給的輸入，答案在第 N+1 個週期的輸出才看到。

logic signed [15:0] result;

always_comb begin           // 1) 組合：算答案
    case (ctrl)
        2'b00:   result = ...;
        default: result = ...;
    endcase
end

always_ff @(posedge clk) begin   // 2) 循序：存起來
    if (rst) out <= '0;
    else     out <= result;
end

計數器：最基本的循序電路

logic [3:0] cnt;
always_ff @(posedge clk) begin
    if (rst)               cnt <= '0;
    else if (en) begin
        if (cnt == 4'd9)   cnt <= '0;        // 0~9 循環
        else               cnt <= cnt + 4'd1;
    end
end

實例化（instantiation）：把模組接起來

// 1) 依名稱（推薦，考試範本也要求）
mux u_mux (.a(and_ab), .b(or_ab), .c(C), .y(out));

// 2) .name 簡寫：外面的訊號名稱跟 port 一樣時
debounce u_db (.clk, .pb, .pb_debounced);   // 外面剛好有同名訊號 clk、pb、pb_debounced

// 3) .* 全部自動接同名訊號（testbench 很常用）
exam1_A dut (.*);

// 參數覆寫
clock_divider #(.n(25)) u_cd (.clk(clk), .clk_div(clk_25));   // n 改成 25
注意依「順序」接（mux u(a, b, c, y);）容易接錯，Lab 1 testbench 也明確要求用名稱接。

Gate-level（Lab 1）

內建的邏輯閘 primitive：and or not nand nor xor xnor buf。第一個 port 是輸出，後面是輸入。

module mux (input wire a, b, c, output wire y);   // c=0 -> a, c=1 -> b
    wire c_n, t0, t1;
    not g0 (c_n, c);
    and g1 (t0, a, c_n);
    and g2 (t1, b, c);
    or  g3 (y, t0, t1);
endmodule

一個檔案放多個模組

C 題要求「所有模組放同一個檔案」。考試提供的 clock_divider、debounce、onepulse、SevenSegment 通常已經在範本檔案裡，直接在主模組裡實例化就好。自己加的子模組寫在 endmodule 後面，順序沒關係。不要重複定義同名模組（例如範本已經有 debounce，你又貼一個）。

同一個電路的兩種寫法

module cnt(input clk, input rst, output reg [3:0] q);
    parameter IDLE = 1'b0, RUN = 1'b1;
    reg state;
    always @(posedge clk) begin
        if (rst) begin
            q <= 4'd0; state <= IDLE;
        end else begin
            state <= RUN;
            if (state == RUN) q <= q + 1;
        end
    end
endmodule
module cnt(input logic clk, rst, output logic [3:0] q);
    typedef enum logic {IDLE, RUN} state_t;
    state_t state;
    always_ff @(posedge clk) begin
        if (rst) begin
            q <= '0; state <= IDLE;
        end else begin
            state <= RUN;
            if (state == RUN) q <= q + 1'b1;
        end
    end
endmodule
檔案Vivado 新增檔案時選 SystemVerilog，副檔名 .sv。如果範本是 .v 但你用了 logic、always_ff，要把副檔名改成 .sv（或在 Vivado 裡把檔案類型改成 SystemVerilog），不然會語法錯誤。
