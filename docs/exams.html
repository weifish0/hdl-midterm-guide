九題全部改寫成 SystemVerilog。A、B 題都通過驗證：2023 用助教原本的 testbench 與 pattern（28/28、30/30），2021、2022 用依題目規則寫的參考模型產生 800 組 pattern 驗證。C 題都在 Vivado 合成成功，並用縮短時間的模擬檢查過題目的範例情境。

C 題直接用考試提供的模組老師說考試會提供 clock_divider、debounce、onepulse、SevenSegment 和 XDC。三年的 C 題解答都只用這些模組：按鈕走 debounce → one_pulse，速度用 clock_divider + one_pulse 變成 tick，顯示交給 SevenSegment（只在它的 case 表裡加題目需要的字母）。

A · 同步 ALU（30%）

題意

輸入 A、B 為 8-bit 有號數，ctrl 2 bits，輸出 out 16-bit 有號，前面加一級 flip-flop（晚一拍），同步 reset 時輸出 0。

ctrl功能例子
00A*B + 3（符號延伸）A=-7、B=5 → -32
01{A & B, A ^ B}A=1110_0010、B=1100_1110 → 1100_0010_0010_1100
11(A + B) << 2（符號延伸）7 + 12 = 19 → 76
其他（10）A/4 > B ? 1 : -1，不能用 /A=8、B=3：2 > 3 不成立 → -1

思路

  • A、B 宣告成 logic signed [7:0]，result 宣告成 logic signed [15:0]，所有運算自然在 16 bits 有號 context 下完成。
  • + 3 寫 16'sd3 或 3，不要寫 16'd3（會讓整個式子變無號）。
  • (A + B) << 2：因為左邊 16 bits，A+B 會先在 16 bits 算，不會在 8 bits 溢位。
  • A/4 → A >>> 2（算術右移保留符號）。
解答：exam1_A.sv（官方 testbench 28/28）
// 2023 Exam1 Problem A — Synchronous ALU (SystemVerilog reference solution)
`timescale 1ns/1ps
module exam1_A (
    input  logic              clk,
    input  logic              rst,      // synchronous, active-high
    input  logic signed [7:0] A,
    input  logic signed [7:0] B,
    input  logic        [1:0] ctrl,
    output logic signed [15:0] out
);
    logic signed [15:0] result;   // combinational result (next value of out)

    // 1) Combinational part: compute the answer for the CURRENT inputs
    always_comb begin
        case (ctrl)
            // A*B+3 : every operand is signed, so the whole expression is
            // sign-extended to the 16-bit context before multiplying.
            2'b00:   result = A * B + 16'sd3;
            // {A&B, A^B}: a concatenation is just bits (8 + 8 = 16 bits)
            2'b01:   result = {A & B, A ^ B};
            // (A+B)<<2 : evaluated in 16 bits, so no overflow of the 8-bit sum
            2'b11:   result = (A + B) <<< 2;
            // A/4 > B without "/" : arithmetic right shift by 2 keeps the sign
            default: result = ((A >>> 2) > B) ? 16'sd1 : -16'sd1;
        endcase
    end

    // 2) Sequential part: one flip-flop in front of the output port
    always_ff @(posedge clk) begin
        if (rst) out <= 16'sd0;     // synchronous reset -> only at the clock edge
        else     out <= result;
    end
endmodule
易錯A 沒宣告 signed 時 A >>> 2 等於 A >> 2（補 0），負數全錯。{A & B, A ^ B} 是串接，不要寫成 (A & B) << 8 | ... 還搞錯寬度。

B · Hamming 碼更正 + 運算（30%）

題意

12-bit 輸入 data（B12…B1，B1 = data[0]），其中 B1、B2、B4、B8 是冗餘位元 r1–r4，其餘 8 個是資料 d1–d8。每筆資料剛好有（最多）一個 bit 錯誤。

  1. 算 c1 = B1⊕B3⊕B5⊕B7⊕B9⊕B11、c2 = B2⊕B3⊕B6⊕B7⊕B10⊕B11、c3 = B4⊕B5⊕B6⊕B7⊕B12、c4 = B8⊕B9⊕B10⊕B11⊕B12。
  2. {c4,c3,c2,c1} 的值就是錯誤位置（0 = 沒錯），把那個 bit 反相。
  3. 去掉冗餘位元得到 decoded = {d8..d1} = {B12,B11,B10,B9,B7,B6,B5,B3}。
  4. request = decoded[7:6]，a = decoded[5:3]，b = decoded[2:0]；00 → a&b、01 → a|b、10 → a、11 → b。

例：0100_0010_1100（左邊是 B12）。算出 c4 c3 c2 c1 = 1 0 1 0 = 10，所以 B10 錯了，翻回來後 decoded = 01100101；request = 01（or），a = 100、b = 101，out = 101。

思路

全部都是組合邏輯，最後兩個輸出各加一級暫存器。最優雅的寫法是「用 syndrome 當 index 直接翻那個 bit」：fixed[syndrome - 1] = ~data[syndrome - 1];。也可以用 12 個 case 分支，比較長但不容易錯。

解答：exam1_B.sv（官方 testbench 30/30）
// 2023 Exam1 Problem B — Hamming(12,8) single-error correction + tiny ALU
`timescale 1ns/1ps
module exam1_B (
    input  logic        clk,
    input  logic        rst,            // synchronous, active-high
    input  logic [11:0] data,           // data[0] = B1 ... data[11] = B12
    output logic [7:0]  decoded,
    output logic [2:0]  out
);
    logic [3:0]  syndrome;              // {c4, c3, c2, c1}
    logic [11:0] fixed;                 // corrected code word
    logic [7:0]  dec_c;                 // combinational decoded data
    logic [2:0]  out_c;                 // combinational final output

    always_comb begin
        // B(k) is data[k-1]
        syndrome[0] = data[0] ^ data[2] ^ data[4] ^ data[6] ^ data[8] ^ data[10]; // c1: B1 B3 B5 B7 B9 B11
        syndrome[1] = data[1] ^ data[2] ^ data[5] ^ data[6] ^ data[9] ^ data[10]; // c2: B2 B3 B6 B7 B10 B11
        syndrome[2] = data[3] ^ data[4] ^ data[5] ^ data[6] ^ data[11];           // c3: B4 B5 B6 B7 B12
        syndrome[3] = data[7] ^ data[8] ^ data[9] ^ data[10] ^ data[11];          // c4: B8 B9 B10 B11 B12

        // The syndrome IS the position of the wrong bit (1..12); 0 = no error
        fixed = data;
        if (syndrome != 4'd0 && syndrome <= 4'd12)
            fixed[syndrome - 4'd1] = ~data[syndrome - 4'd1];

        // drop r1(B1) r2(B2) r3(B4) r4(B8): keep d8..d1 = B12 B11 B10 B9 B7 B6 B5 B3
        dec_c = {fixed[11], fixed[10], fixed[9], fixed[8],
                 fixed[6],  fixed[5],  fixed[4], fixed[2]};

        // request = dec[7:6], a = dec[5:3], b = dec[2:0]
        case (dec_c[7:6])
            2'b00: out_c = dec_c[5:3] & dec_c[2:0];
            2'b01: out_c = dec_c[5:3] | dec_c[2:0];
            2'b10: out_c = dec_c[5:3];
            2'b11: out_c = dec_c[2:0];
        endcase
    end

    always_ff @(posedge clk) begin
        if (rst) begin
            decoded <= 8'd0;
            out     <= 3'd0;
        end else begin
            decoded <= dec_c;
            out     <= out_c;
        end
    end
endmodule
易錯位置從 1 開始數，陣列 index 從 0 開始：Bk 是 data[k-1]。decoded 的順序是 d8 在最高位。

C · 兩條蛇吃蘋果（40%）

題意

項目規格
按鈕rst = BTNC（同步）、en = BTNR、set = BTNL、up = BTNU、down = BTND
RESETSnake111（3 格）在 LD15–13，mode 1；Snake1（1 格）在 LD0。不動、不能改 mode。按 en → START
START：計時每 226 週期 +1；從 9 變 10 時結束
START：蘋果按 set 時把 sw 為 1 的位置加上蘋果（不能放在蛇身上）
START：移動Snake111 初始往右、速度依 mode：224/225/226（up/down 調整）；Snake1 初始往左、225
START：轉向碰到 LD0 或 LD15；或 Snake111 右端與 Snake1 相鄰或重疊時，Snake111 轉左、Snake1 轉右
START：得分蛇碰到蘋果得 1 分、蘋果消失；同時碰到給 Snake111
七段顯示左兩位：計時器；右兩位：Snake111 − Snake1 的分差（負數顯示 "-"），例如 "03 2"、"07-1"
FINISH計時到 10 或分差 ≥ 3 時進入。顯示 "S111" / "--S1" / "----"；LED 全亮；按 en → RESET
stateDiagram-v2
    direction LR
    RESET --> START: en
    START --> FINISH: timer = 10 或 |分差| ≥ 3
    FINISH --> RESET: en

思路

  • 用提供的 clock_divider（n = 24、25、26）加 one_pulse(~clk_div) 產生 t24、t25、t26 三個 tick，三者自動對齊（見 設計模式 → tick）；Snake111 依 mode 選其中一個。
  • Snake111 只存左端 p，右端 r = p - 2，遮罩 16'b111 << r。Snake1 存位置 q。
  • 每個 clk 都根據現在位置算「有效方向」：相鄰（q + 1 >= r）優先、再來是撞邊界。題目範例要求「Snake1 先動、Snake111 還沒動時就已經判定相撞，下一步兩條都要轉向」，所以方向不能只在自己的 tick 才更新。
  • 蘋果是 16-bit bitmap：apple <= (apple & ~occ) | (set_p ? sw & ~occ : 0)，一行同時處理被吃掉與新增。
  • 分差用有號數：diff = $signed({1'b0, s111}) - $signed({1'b0, s1})。
解答：exam1_C.sv（使用提供的模組；Vivado 合成成功；模擬驗證碰撞反彈、平手歸屬、計時結束）
// 2023 Exam1 Problem C — Two snakes eating apples (SystemVerilog reference solution)
// Built from the PROVIDED modules: clock_divider, debounce, one_pulse, SevenSegment.
// One clock (100 MHz) for all logic; slow events are 1-cycle tick pulses.
//   T0 = 24 -> t24 every 2^24, t25 every 2^25, t26 every 2^26 cycles.
//   (For simulation, override T0 / DB with small numbers.)
`timescale 1ns/1ps
module exam1_C #(parameter int T0 = 24, parameter int DB = 16) (
    input  logic        clk,
    input  logic        rst,      // btnC, synchronous active-high
    input  logic        en,       // btnR
    input  logic        set,      // btnL
    input  logic        up,       // btnU
    input  logic        down,     // btnD
    input  logic [15:0] sw,
    output logic [3:0]  DIGIT,
    output logic [6:0]  DISPLAY,
    output logic [15:0] led
);
    // ---------------- buttons: provided debounce + one_pulse ----------------
    // debounce samples on a slow clock (every 2^DB cycles, ~0.65 ms) so its 8 samples
    // cover ~5 ms of bouncing; one_pulse runs on the 100 MHz clk, so each press becomes
    // exactly ONE clk cycle that the FSM below cannot miss.
    logic clk_db;
    clock_divider #(.n(DB)) u_cd_db (.clk(clk), .clk_div(clk_db));
    logic en_d, set_d, up_d, down_d;
    logic en_p, set_p, up_p, down_p;
    debounce  u_db_en   (.clk(clk_db), .pb(en), .pb_debounced(en_d));
    one_pulse u_op_en   (.clk(clk),    .pb_in(en_d), .pb_out(en_p));
    debounce  u_db_set  (.clk(clk_db), .pb(set), .pb_debounced(set_d));
    one_pulse u_op_set  (.clk(clk),    .pb_in(set_d), .pb_out(set_p));
    debounce  u_db_up   (.clk(clk_db), .pb(up), .pb_debounced(up_d));
    one_pulse u_op_up   (.clk(clk),    .pb_in(up_d), .pb_out(up_p));
    debounce  u_db_down (.clk(clk_db), .pb(down), .pb_debounced(down_d));
    one_pulse u_op_down (.clk(clk),    .pb_in(down_d), .pb_out(down_p));

    // ---------------- FSM ----------------
    typedef enum logic [1:0] {S_RESET, S_START, S_FINISH} state_t;
    state_t state;

    // ---------------- ticks: provided clock_divider + one_pulse ----------------
    // clk_div falls (1 -> 0) exactly when its counter wraps, i.e. once every 2^n cycles.
    // one_pulse(~clk_div) turns that moment into a 1-cycle "tick" in the 100 MHz domain.
    // All dividers start at 0, so every 2^(T0+2) tick also lands on a 2^(T0+1) and 2^T0 tick.
    logic cd0, cd1, cd2, t24, t25, t26;
    clock_divider #(.n(T0))   u_cd0 (.clk(clk), .clk_div(cd0));
    clock_divider #(.n(T0+1)) u_cd1 (.clk(clk), .clk_div(cd1));
    clock_divider #(.n(T0+2)) u_cd2 (.clk(clk), .clk_div(cd2));
    one_pulse u_t0 (.clk(clk), .pb_in(~cd0), .pb_out(t24));   // every 2^24 cycles
    one_pulse u_t1 (.clk(clk), .pb_in(~cd1), .pb_out(t25));   // every 2^25
    one_pulse u_t2 (.clk(clk), .pb_in(~cd2), .pb_out(t26));   // every 2^26
    logic tick0, tick1, tick2;
    assign tick0 = (state == S_START) && t24;
    assign tick1 = (state == S_START) && t25;
    assign tick2 = (state == S_START) && t26;

    // ---------------- game registers ----------------
    localparam logic L = 1'b1, R = 1'b0;   // L: toward LD15 (index +1), R: toward LD0 (index -1)
    logic [3:0]  p;        // Snake111 LEFT end; it occupies p, p-1, p-2
    logic        d111;
    logic [1:0]  mode;     // 0: 2^24, 1: 2^25, 2: 2^26
    logic [3:0]  q;        // Snake1 position
    logic        d1;
    logic [15:0] apple;
    logic [4:0]  s111, s1; // scores
    logic [3:0]  timer;    // 0..10

    // ---------------- combinational helpers ----------------
    logic [15:0] mask111, mask1, occ;
    logic [3:0]  r;                       // right end of Snake111
    logic        contact, eff111, eff1, tick111;
    logic signed [5:0] diff;
    logic        hit111, hit1, game_over;

    assign r       = p - 4'd2;
    assign mask111 = 16'b111 << r;
    assign mask1   = 16'b1 << q;
    assign occ     = mask111 | mask1;

    // contact: the two ends are next to each other OR overlap (q is always right of r)
    assign contact = ({1'b0, q} + 5'd1 >= {1'b0, r});

    // effective direction for THIS cycle (contact has the highest priority)
    always_comb begin
        if (contact)           eff111 = L;
        else if (p == 4'd15)   eff111 = R;
        else if (r == 4'd0)    eff111 = L;
        else                   eff111 = d111;

        if (contact)           eff1 = R;
        else if (q == 4'd0)    eff1 = L;
        else if (q == 4'd15)   eff1 = R;
        else                   eff1 = d1;
    end

    always_comb begin
        case (mode)
            2'd0:    tick111 = tick0;
            2'd1:    tick111 = tick1;
            default: tick111 = tick2;
        endcase
    end

    // eating: Snake111 has priority when both touch the same apple
    assign hit111 = |(apple & mask111);
    assign hit1   = |(apple & mask1 & ~mask111);

    assign diff      = $signed({1'b0, s111}) - $signed({1'b0, s1});
    assign game_over = (timer == 4'd10) || (diff >= 6'sd3) || (diff <= -6'sd3);

    // ---------------- main sequential block ----------------
    always_ff @(posedge clk) begin
        if (rst || (state == S_FINISH && en_p)) begin
            state <= S_RESET;
            p     <= 4'd15;  d111 <= R;  mode <= 2'd1;
            q     <= 4'd0;   d1   <= L;
            apple <= '0;
            s111  <= '0;     s1   <= '0;
            timer <= '0;
        end else begin
            case (state)
                S_RESET: if (en_p) state <= S_START;

                S_START: begin
                    // directions are re-evaluated every cycle
                    d111 <= eff111;
                    d1   <= eff1;

                    // movement (stay in place if blocked on both sides)
                    if (tick111) begin
                        if (eff111 == L && p != 4'd15)                  p <= p + 4'd1;
                        else if (eff111 == R && r != 4'd0 && !contact)  p <= p - 4'd1;
                    end
                    if (tick1) begin
                        if (eff1 == R && q != 4'd0)                     q <= q - 4'd1;
                        else if (eff1 == L && q != 4'd15 && !contact)   q <= q + 4'd1;
                    end

                    // mode change (only in START)
                    if (up_p   && mode != 2'd2) mode <= mode + 2'd1;
                    if (down_p && mode != 2'd0) mode <= mode - 2'd1;

                    // apples: remove eaten ones, add new ones (never on a snake)
                    apple <= (apple & ~occ) | (set_p ? (sw & ~occ) : 16'd0);
                    if (hit111) s111 <= s111 + 5'd1;
                    if (hit1)   s1   <= s1 + 5'd1;

                    // timer (~1 s)
                    if (tick2 && timer != 4'd10) timer <= timer + 4'd1;

                    if (game_over) state <= S_FINISH;
                end

                default: ;  // S_FINISH: wait for en (handled above)
            endcase
        end
    end

    // ---------------- outputs ----------------
    // SevenSegment shows nums[15:12] on the LEFTMOST digit ... nums[3:0] on the rightmost.
    // codes: 0-9 digits, 5 doubles as 'S', 12 = blank, 15 = '-'
    localparam logic [3:0] BLANK = 4'd12, DASH = 4'd15;
    logic [15:0] nums;
    logic [5:0]  abs_diff;
    assign abs_diff = diff[5] ? -diff : diff;

    always_comb begin
        if (state == S_FINISH) begin
            led = 16'hFFFF;
            if (diff > 0)      nums = {4'd5, 4'd1, 4'd1, 4'd1};     // "S111"
            else if (diff < 0) nums = {DASH, DASH, 4'd5, 4'd1};     // "--S1"
            else               nums = {DASH, DASH, DASH, DASH};     // "----"
        end else begin
            led  = apple | occ;
            nums = {(timer == 4'd10) ? 4'd1 : 4'd0,                 // timer tens
                    (timer == 4'd10) ? 4'd0 : timer,                // timer ones
                    diff[5] ? DASH : BLANK,                         // sign
                    abs_diff[3:0]};                                 // |diff|
        end
    end

    SevenSegment u_seg (.display(DISPLAY), .digit(DIGIT), .nums(nums), .rst(rst), .clk(clk));
endmodule

// ===================================================================
// Provided modules (given in the exam: clock_divider, debounce, one_pulse,
// SevenSegment). Pasted unchanged, except: SevenSegment got codes 12 (blank) and 15 (-).
// ===================================================================
module clock_divider #(
    parameter n = 27 // 2^27 / 100M Hz = 1.34s
)(
    input logic  clk,
    output logic clk_div  
);

    logic [n-1:0] num;
    logic [n-1:0] next_num;

    always_ff @(posedge clk) begin
        num <= next_num;
    end

    assign next_num = num + 1'b1;
    assign clk_div = num[n-1];
endmodule


module debounce #(
    parameter n = 8
)(
    input logic clk,
    input logic pb,
    output logic pb_debounced
);

    logic [n-1:0] shift_reg;

    always_ff @(posedge clk) begin
        shift_reg[n-1:1] <= shift_reg[n-2:0];
        shift_reg[0] <= pb;
    end

    assign pb_debounced = &shift_reg;
endmodule


module one_pulse (
    input logic clk,
    input logic pb_in,
    output logic pb_out
);

	logic pb_in_delay;

	always_ff @(posedge clk) begin
		pb_out <= (pb_in & ~pb_in_delay);
		pb_in_delay <= pb_in;
	end
endmodule


module SevenSegment(
	output logic [6:0] display,
	output logic [3:0] digit,
	input logic [15:0] nums,
	input logic rst,
	input logic clk
);
    
    logic [15:0] clk_divider;
    logic [3:0] display_num;
    
    always_ff @(posedge clk or posedge rst) begin
    	if (rst) begin
    		clk_divider <= 16'd0;
    	end else begin
    		clk_divider <= clk_divider + 16'd1;
    	end
    end
    
    always_ff @(posedge clk_divider[15] or posedge rst) begin
    	if (rst) begin
    		display_num <= 4'b0000;
    		digit <= 4'b1111;
    	end else begin
    		case (digit)
    			4'b1110 : begin
					display_num <= nums[7:4];
					digit <= 4'b1101;
    			end
    			4'b1101 : begin
					display_num <= nums[11:8];
					digit <= 4'b1011;
				end
    			4'b1011 : begin
					display_num <= nums[15:12];
					digit <= 4'b0111;
				end
    			4'b0111 : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end
    			default : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end				
    		endcase
    	end
    end
    
    always_comb begin
    	case (display_num)
    		4'd0: display = 7'b1000000;
            4'd1: display = 7'b1111001;
            4'd2: display = 7'b0100100;
            4'd3: display = 7'b0110000;
            4'd4: display = 7'b0011001;
            4'd5: display = 7'b0010010;
            4'd6: display = 7'b0000010;
            4'd7: display = 7'b1111000;
            4'd8: display = 7'b0000000;
            4'd9: display = 7'b0010000;
            4'd12: display = 7'b1111111;   // blank  <- added for this problem
            4'd15: display = 7'b0111111;   // -  <- added for this problem
			default : display = 7'b1111111;
    	endcase
    end
endmodule
易錯
  • 蛇111 用 226 的 clk_div 當時脈、Snake1 用 225：兩個時脈領域無法正確判斷相撞，按鈕脈衝也會漏。
  • 計時器「從 9 變 10」就要結束，FINISH 不顯示 10。
  • 蘋果加在蛇身上要無效：sw & ~occ。

A · 同步 ALU（30%）

ctrl功能例子
00A * (-B)A=5、B=-6 → 30
01{A ^ B, ~(A | B)}（xor 串 nor）0110_0110、0100_0111 → 0010_0001_1001_1000
11A + B8 + 9 = 17
其他A < B ? -1 : 1A=8、B=6 → 1

思路

跟 2023 一樣的骨架。唯一陷阱是 -B：B = -128 時，8-bit 的 -B 溢位還是 -128。寫在 16-bit 的式子裡（result = A * (-B)）就沒事，因為 B 會先延伸到 16 bits 再取負。

解答：exam1_A.sv（800 組參考模型 pattern 全對，含 ±128 邊界）
// 2022 Exam1 Problem A — Synchronous ALU (SystemVerilog reference solution)
`timescale 1ns/1ps
module exam1_A (
    input  logic               clk,
    input  logic               rst,     // synchronous, active-high
    input  logic signed [7:0]  A,
    input  logic signed [7:0]  B,
    input  logic        [1:0]  ctrl,
    output logic signed [15:0] out
);
    logic signed [15:0] result;

    always_comb begin
        case (ctrl)
            // -B is evaluated in the 16-bit context, so B = -128 becomes +128
            // correctly (in 8 bits, -(-128) would overflow back to -128!)
            2'b00:   result = A * (-B);
            2'b01:   result = {A ^ B, ~(A | B)};          // xor ++ nor
            2'b11:   result = A + B;
            default: result = (A < B) ? -16'sd1 : 16'sd1; // both signed -> signed compare
        endcase
    end

    always_ff @(posedge clk) begin
        if (rst) out <= '0;
        else     out <= result;
    end
endmodule

B · 類費氏計數器（30%）

題意

設 ci 為目前值，ci-1 為前一個值，S = ci-1 + ci，i 從 1 開始。

上數（不能用 /），c0=0、c1=1

  • S%4 = 0 且 S < 16384：(S/2)×3
  • S%4 = 0 且 S ≥ 16384：ci + i
  • S%4 ≠ 0 且 i 奇數：ci + 4
  • S%4 ≠ 0 且 i 偶數：ci + 1
到 65176 時轉下數。

下數（不能用 %），c0=64752、c1=65176

  • S%8 = i%8：ci >> (i%4)
  • 否則：ci − 6i
結果為負就設 0 並結束，再從 1 開始上數。

序列：1 → 5 → 6 → 10 → 24 → … → 64752 → 65176 → 65170 → 16292 → … → 77 → 0 → 1 → 5 …

思路

  1. 先在紙上（或用 Python）算出前幾項，確認看懂規則。
  2. 暫存器：out（ci）、prev（ci-1）、i、方向 up。
  3. S 最大約 130000，要 17 bits。16 bits 會溢位。
  4. 取餘數全部換成取低位元：S[1:0]、S[2:0] == i[2:0]、i[1:0]、i[0]。
  5. (S/2)×3 = (S >> 1) + ((S >> 1) << 1)；6i = (i << 2) + (i << 1)。
  6. 下數的「變負」：先比較 out < 6i，不要真的做減法再看符號（無號數減成負會變成很大的正數）。
解答：exam1_B.sv（連續 1500 拍與參考模型完全一致，跨越兩次上下數循環）
// 2022 Exam1 Problem B — Fibonacci-like up/down counter (SystemVerilog reference solution)
// No "/" in count-up and no "%" in count-down: use shifts and bit slices instead.
`timescale 1ns/1ps
module exam1_B (
    input  logic        clk,
    input  logic        rst,      // synchronous, active-high
    output logic [15:0] out       // c_i (current value)
);
    localparam logic [15:0] TOP = 16'd65176;

    logic        up;
    logic [15:0] prev;            // c_(i-1)
    logic [15:0] i;
    logic [16:0] S;               // c_(i-1) + c_i  (needs 17 bits!)
    logic [16:0] nxt;             // c_(i+1), one extra bit for the sign check
    logic [16:0] six_i;

    assign S     = prev + out;
    assign six_i = (i << 2) + (i << 1);          // 6*i = 4i + 2i

    always_comb begin
        if (up) begin
            if (S[1:0] == 2'b00)                   // S % 4 == 0
                nxt = (S < 17'd16384) ? (S >> 1) + ((S >> 1) << 1)   // (S/2)*3
                                      : out + i;
            else
                nxt = i[0] ? out + 16'd4 : out + 16'd1;           // i odd / even
        end else begin
            if (S[2:0] == i[2:0])                   // S % 8 == i % 8
                nxt = out >> i[1:0];                // c_i >> (i % 4)
            else if (out < six_i)                   // would become negative
                nxt = 17'd0;
            else
                nxt = out - six_i;
        end
    end

    always_ff @(posedge clk) begin
        if (rst) begin
            // reset to 0; the "restart" branch below makes the next value 1
            out <= 16'd0; prev <= 16'd0; i <= 16'd1; up <= 1'b1;
        end else if (up && out == 16'd0) begin   // restart: c0 = 0, c1 = 1
            out <= 16'd1; prev <= 16'd0; i <= 16'd1;
        end else begin
            prev <= out;
            out  <= nxt[15:0];
            if (up && nxt[15:0] == TOP) begin     // reached the top -> count down
                up <= 1'b0; i <= 16'd1;           // down: c0 = 64752, c1 = 65176
            end else if (!up && nxt[15:0] == 16'd0) begin
                up <= 1'b1; i <= 16'd1;           // finished counting down
            end else begin
                i <= i + 16'd1;
            end
        end
    end
endmodule
reset 後輸出什麼？題目沒有明講 reset 時輸出 0 還是 1，2022 年的 testbench 我們沒有。本解 reset 輸出 0、下一拍輸出 1（等同下數結束後的重新開始）。考試時請看 testbench 怎麼比對第一筆。

C · AI 與玩家搶旗子（40%）

項目規格
按鈕rst = BTNC、en = BTNR（RESET→START、START↔PAUSE）、set = BTNL（依 sw 加旗子）、up/down 改玩家模式
RESETAI 在 LD15；玩家在 LD2–LD0（mode 1）
AI1 格，每 225 移動，初始由左往右（LD0 之後是 LD15），撞到玩家就反向
玩家永遠由右往左（LD15 之後是 LD0）。mode 0：1 格、224；mode 1：3 格、225；mode 2：5 格、226；改 mode 時從兩側伸縮
得分碰到旗子 +1、旗子消失；同時碰到給 AI。七段左兩位 AI 分數、右兩位玩家分數
FINISH任一方 10 分。顯示 "AIAI" 或 "USER"（R 只能用小寫 r 表示）；LED 以 224 在 0101… 與 1010… 間閃爍

思路

  • 玩家存「中心」uc 和 mode。遮罩先做一個以 bit 0 為中心的基本圖形（mode 1 = bit 15、0、1），再環狀左旋 uc 位：(base << uc) | (base >> (16 - uc))。這樣跨越 LD15/LD0 邊界、從兩側伸縮都自動正確。
  • 4-bit 位置的加減自動環繞（15 + 1 = 0）。
  • AI 撞玩家：在 AI 要移動的那一拍，看「玩家這一拍之後的位置」是否擋在前面（兩者可能同一拍移動）。
解答：exam1_C.sv（使用提供的模組；Vivado 合成成功；模擬驗證搶旗、平手、反彈、PAUSE）
// 2022 Exam1 Problem C — player_AI vs player_user grabbing flags (SystemVerilog reference solution)
// Built from the PROVIDED modules: clock_divider, debounce, one_pulse, SevenSegment.
// One clock (100 MHz) for all logic; t24 / t25 / t26 are 1-cycle tick pulses.
`timescale 1ns/1ps
module exam1_C #(parameter int T0 = 24, parameter int DB = 16) (
    input  logic        clk,
    input  logic        rst,      // btnC, synchronous active-high
    input  logic        en,       // btnR : RESET->START, START<->PAUSE
    input  logic        set,      // btnL : add flags where sw = 1
    input  logic        up,       // btnU : bigger & slower
    input  logic        down,     // btnD : smaller & faster
    input  logic [15:0] sw,
    output logic [3:0]  DIGIT,
    output logic [6:0]  DISPLAY,
    output logic [15:0] led
);
    // ---------------- buttons: provided debounce + one_pulse ----------------
    // debounce samples on a slow clock (every 2^DB cycles, ~0.65 ms) so its 8 samples
    // cover ~5 ms of bouncing; one_pulse runs on the 100 MHz clk, so each press becomes
    // exactly ONE clk cycle that the FSM below cannot miss.
    logic clk_db;
    clock_divider #(.n(DB)) u_cd_db (.clk(clk), .clk_div(clk_db));
    logic en_d, set_d, up_d, down_d;
    logic en_p, set_p, up_p, down_p;
    debounce  u_db_en   (.clk(clk_db), .pb(en), .pb_debounced(en_d));
    one_pulse u_op_en   (.clk(clk),    .pb_in(en_d), .pb_out(en_p));
    debounce  u_db_set  (.clk(clk_db), .pb(set), .pb_debounced(set_d));
    one_pulse u_op_set  (.clk(clk),    .pb_in(set_d), .pb_out(set_p));
    debounce  u_db_up   (.clk(clk_db), .pb(up), .pb_debounced(up_d));
    one_pulse u_op_up   (.clk(clk),    .pb_in(up_d), .pb_out(up_p));
    debounce  u_db_down (.clk(clk_db), .pb(down), .pb_debounced(down_d));
    one_pulse u_op_down (.clk(clk),    .pb_in(down_d), .pb_out(down_p));

    typedef enum logic [1:0] {S_RESET, S_START, S_PAUSE, S_FINISH} state_t;
    state_t state;

    // ---------------- ticks: provided clock_divider + one_pulse ----------------
    // clk_div falls (1 -> 0) exactly when its counter wraps, i.e. once every 2^n cycles.
    // one_pulse(~clk_div) turns that moment into a 1-cycle "tick" in the 100 MHz domain.
    // All dividers start at 0, so every 2^(T0+2) tick also lands on a 2^(T0+1) and 2^T0 tick.
    logic cd0, cd1, cd2, t24, t25, t26;
    clock_divider #(.n(T0))   u_cd0 (.clk(clk), .clk_div(cd0));
    clock_divider #(.n(T0+1)) u_cd1 (.clk(clk), .clk_div(cd1));
    clock_divider #(.n(T0+2)) u_cd2 (.clk(clk), .clk_div(cd2));
    one_pulse u_t0 (.clk(clk), .pb_in(~cd0), .pb_out(t24));   // every 2^24 cycles
    one_pulse u_t1 (.clk(clk), .pb_in(~cd1), .pb_out(t25));   // every 2^25
    one_pulse u_t2 (.clk(clk), .pb_in(~cd2), .pb_out(t26));   // every 2^26

    // ---------------- players ----------------
    logic [3:0]  ai;          // AI position
    logic        ai_left;     // 0: moving toward LD0 (index -1, wraps 0 -> 15), 1: toward LD15
    logic [3:0]  uc;          // user CENTER position, always moves toward LD15 (wraps 15 -> 0)
    logic [1:0]  mode;        // 0: 1 LED @2^24, 1: 3 LEDs @2^25, 2: 5 LEDs @2^26
    logic [15:0] flag;
    logic [3:0]  ai_sc, us_sc;
    logic        led_phase;   // FINISH flashing

    // user mask = base pattern centred at bit 0, rotated left by uc (wrap-around for free)
    logic [15:0] base, umask, amask;
    always_comb begin
        case (mode)
            2'd0:    base = 16'b0000_0000_0000_0001;  // {0}
            2'd1:    base = 16'b1000_0000_0000_0011;  // {15,0,1}
            default: base = 16'b1100_0000_0000_0111;  // {14,15,0,1,2}
        endcase
    end
    assign umask = (base << uc) | (base >> (5'd16 - uc));   // rotate-left (uc = 0 is fine)
    assign amask = 16'b1 << ai;


    logic u_tick;
    always_comb begin
        case (mode)
            2'd0:    u_tick = t24;
            2'd1:    u_tick = t25;
            default: u_tick = t26;
        endcase
    end

    // where the user WILL be after this edge (both players may move on the same edge)
    logic [3:0]  uc_n;
    logic [15:0] umask_n;
    assign uc_n    = u_tick ? uc + 4'd1 : uc;
    assign umask_n = (base << uc_n) | (base >> (5'd16 - uc_n));

    // AI next step / bounce
    // The user always moves toward LD15. If the user is about to cover the AI while the
    // AI is heading toward it (head-on), the AI turns around right now.
    logic       eff_left;
    logic [3:0] ai_fwd, ai_back;
    assign eff_left = (umask_n[ai] && !ai_left) ? 1'b1 : ai_left;
    assign ai_fwd   = eff_left ? ai + 4'd1 : ai - 4'd1;   // 4-bit wrap-around: 0-1 = 15
    assign ai_back  = eff_left ? ai - 4'd1 : ai + 4'd1;

    logic ai_hit, us_hit;
    assign ai_hit = |(flag & amask);
    assign us_hit = |(flag & umask & ~amask);     // AI wins a tie

    always_ff @(posedge clk) begin
        if (rst) begin
            state <= S_RESET;
            ai <= 4'd15; ai_left <= 1'b0;
            uc <= 4'd1;  mode <= 2'd1;
            flag <= '0;  ai_sc <= '0; us_sc <= '0;
            led_phase <= 1'b0;
        end else begin
            // flags can be added in RESET / START / PAUSE
            if (set_p && state != S_FINISH) flag <= flag | sw;

            case (state)
                S_RESET: if (en_p) state <= S_START;

                S_START: begin
                    if (en_p) state <= S_PAUSE;

                    if (up_p   && mode != 2'd2) mode <= mode + 2'd1;  // expands at both sides
                    if (down_p && mode != 2'd0) mode <= mode - 2'd1;  // (centre stays)

                    if (u_tick) uc <= uc + 4'd1;

                    ai_left <= eff_left;
                    if (t25) begin
                        if (umask_n[ai_fwd]) begin            // would hit the user -> turn around
                            ai_left <= ~eff_left;
                            if (!umask_n[ai_back]) ai <= ai_back;
                        end else begin
                            ai <= ai_fwd;
                        end
                    end

                    // touching flags (overrides the "add" above for touched bits)
                    if (ai_hit || us_hit)
                        flag <= (flag | (set_p ? sw : 16'd0)) & ~(amask | umask);
                    if (ai_hit) ai_sc <= ai_sc + 4'd1;
                    if (us_hit) us_sc <= us_sc + 4'd1;

                    if (ai_sc == 4'd10 || us_sc == 4'd10) state <= S_FINISH;
                end

                S_PAUSE: if (en_p) state <= S_START;

                default: if (t24) led_phase <= ~led_phase;   // S_FINISH
            endcase
        end
    end

    // ---------------- outputs ----------------
    // codes for SevenSegment: 0-9 digits (1 = 'I', 5 = 'S'), 10 = A, 11 = E, 13 = U, 14 = r
    localparam logic [3:0] CH_A = 4'd10, CH_E = 4'd11, CH_U = 4'd13, CH_R = 4'd14;
    logic [15:0] nums;
    always_comb begin
        if (state == S_FINISH) begin
            led = led_phase ? 16'hAAAA : 16'h5555;
            if (ai_sc == 4'd10) nums = {CH_A, 4'd1, CH_A, 4'd1};     // "AIAI"
            else                nums = {CH_U, 4'd5, CH_E, CH_R};     // "USEr"
        end else begin
            led  = flag | amask | umask;
            nums = {(ai_sc == 4'd10) ? 4'd1 : 4'd0, (ai_sc == 4'd10) ? 4'd0 : ai_sc,
                    (us_sc == 4'd10) ? 4'd1 : 4'd0, (us_sc == 4'd10) ? 4'd0 : us_sc};
        end
    end

    SevenSegment u_seg (.display(DISPLAY), .digit(DIGIT), .nums(nums), .rst(rst), .clk(clk));
endmodule

// ===================================================================
module clock_divider #(
    parameter n = 27 // 2^27 / 100M Hz = 1.34s
)(
    input logic  clk,
    output logic clk_div  
);

    logic [n-1:0] num;
    logic [n-1:0] next_num;

    always_ff @(posedge clk) begin
        num <= next_num;
    end

    assign next_num = num + 1'b1;
    assign clk_div = num[n-1];
endmodule


module debounce #(
    parameter n = 8
)(
    input logic clk,
    input logic pb,
    output logic pb_debounced
);

    logic [n-1:0] shift_reg;

    always_ff @(posedge clk) begin
        shift_reg[n-1:1] <= shift_reg[n-2:0];
        shift_reg[0] <= pb;
    end

    assign pb_debounced = &shift_reg;
endmodule


module one_pulse (
    input logic clk,
    input logic pb_in,
    output logic pb_out
);

	logic pb_in_delay;

	always_ff @(posedge clk) begin
		pb_out <= (pb_in & ~pb_in_delay);
		pb_in_delay <= pb_in;
	end
endmodule

	output logic [6:0] display,
	output logic [3:0] digit,
	input logic [15:0] nums,
	input logic rst,
	input logic clk
);

    logic [3:0] display_num;

    		clk_divider <= 16'd0;
    	end else begin
    		clk_divider <= clk_divider + 16'd1;
    	end
    end

				end

					display_num <= nums[3:0];
					digit <= 4'b1110;
				end

// 2021 Exam1 Problem A — Synchronous ALU (SystemVerilog reference solution)
`timescale 1ns/1ps
module exam1_A (
    input  logic               clk,
    input  logic               rst,     // synchronous, active-high
    input  logic signed [7:0]  A,
    input  logic signed [7:0]  B,
    input  logic        [1:0]  ctrl,
    output logic signed [15:0] out
);

    always_comb begin
        case (ctrl)
            2'b00:   result = A * B;           // signed x signed -> 16-bit context
            2'b10:   result = {A & B, A | B};  // concatenation (8 + 8 bits)
            2'b11:   result = A >>> 3;         // arithmetic shift keeps the sign

B · 規則計數器（30%）

題意

從 0 上數到 183921，再下數到 0，重複。i 是「這個方向的第 i 步」，從 1 開始。

  • 上數：若 S%8 == i%8，S += 3i；否則 S += i。0 → 1 → 3 → 12 → … → 183395 → 183921
  • 下數：S −= i。183921 → 183920 → 183918 → … → 1211 → 606 → 0
  • 183921 和 0 在轉折處只出現一次。

思路

  • 183921 需要 18 bits；題目給 20 bits 的 result。
  • 上數時算出下一個值 next_val，如果 next_val >= 183921，同時把方向改成下數、i 重設 1。這樣 183921 只會出現一次。
  • 下數時若 result <= i，代表這步會到 0 或以下：輸出 0、方向改回上數。
解答：exam1_B.sv（連續 2500 拍與參考模型一致）
// 2021 Exam1 Problem B — up/down "rule" counter (SystemVerilog reference solution)
`timescale 1ns/1ps
module exam1_B (
    input  logic        clk,
    input  logic        rst,      // synchronous, active-high
    output logic [19:0] result
);
    localparam logic [19:0] MAX = 20'd183921;

    logic        up;      // 1: counting up, 0: counting down
    logic [19:0] i;       // the i-th step inside the current direction (starts at 1)
    logic [19:0] next_val;

    // next value for the up direction  (S % 8 == i % 8  <=>  S[2:0] == i[2:0])
    always_comb begin
        if (result[2:0] == i[2:0]) next_val = result + (i << 1) + i;  // + 3i
        else                       next_val = result + i;
    end

    always_ff @(posedge clk) begin
        if (rst) begin
            result <= 20'd0;
            i      <= 20'd1;
            up     <= 1'b1;
        end else if (up) begin
            result <= next_val;
            if (next_val >= MAX) begin   // reached the top: next step counts down
                up <= 1'b0;
                i  <= 20'd1;
            end else begin
                i  <= i + 20'd1;
            end
        end else begin                   // counting down: S <- S - i
            if (result <= i) begin       // would reach (or pass) 0
                result <= 20'd0;
                up     <= 1'b1;
                i      <= 20'd1;
            end else begin
                result <= result - i;
                i      <= i + 20'd1;
            end
        end
    end
endmodule

C · LED 賽跑者（40%）

項目規格
I/Orst_btn = BTNC、start_btn = BTNL、sw = 牆
RESETMr.1 在 LED1（往左）、Mr.2 在 LED10（往右）；七段最左顯示 "R"、右兩位 00
START每 225 移動一格；撞到對方或牆就反向；LD0 再往右會出現在 LD15。右兩位顯示兩人互撞次數。按 start 或撞滿 15 次 → PAUSE。顯示 "S"
PAUSE停止；按 start 回 START，但已 15 次則不行。顯示 "P"
LEDMr.1、Mr.2、牆都亮

思路：每一步的規則

對每個人：算前進位置 n。如果 n 是牆、是對方現在的位置、或兩人前進位置相同，就「撞到」：反向，並往反方向走一格（反方向也被擋住就原地不動，這就是「卡在兩面牆中間」）。

用題目的情境 1 驗證：Mr.1 在 4、Mr.2 在 7 → 下一步 5、6（相鄰）→ 再下一步兩人的前進位置都是對方 → 反向成 4、7。模擬結果與題目六張圖完全一致。

解答：exam1_C.sv（使用提供的模組；Vivado 合成成功；模擬重現題目情境 1、3、4）
// 2021 Exam1 Problem C — Two LED racers with walls (SystemVerilog reference solution)
// Built from the PROVIDED modules: clock_divider, debounce, one_pulse, SevenSegment.
// One clock (100 MHz) for all logic; racers move on a 1-cycle tick every 2^T cycles.
`timescale 1ns/1ps
module exam1_C #(parameter int T0 = 25, parameter int DB = 16) (
    input  logic        clk,
    input  logic        rst_btn,    // BTNC, synchronous active-high
    input  logic        start_btn,  // BTNL, start / pause
    input  logic [15:0] sw,         // walls
    output logic [3:0]  DIGIT,
    output logic [6:0]  DISPLAY,
    output logic [15:0] led
);
    logic rst;
    assign rst = rst_btn;

    // ---------------- buttons: provided debounce + one_pulse ----------------
    // debounce samples on a slow clock (every 2^DB cycles, ~0.65 ms) so its 8 samples
    // cover ~5 ms of bouncing; one_pulse runs on the 100 MHz clk, so each press becomes
    // exactly ONE clk cycle that the FSM below cannot miss.
    logic clk_db;
    clock_divider #(.n(DB)) u_cd_db (.clk(clk), .clk_div(clk_db));
    logic start_d;
    logic start_p;
    debounce  u_db_start(.clk(clk_db), .pb(start_btn), .pb_debounced(start_d));
    one_pulse u_op_start(.clk(clk),    .pb_in(start_d), .pb_out(start_p));

    typedef enum logic [1:0] {S_RESET, S_START, S_PAUSE} state_t;
    state_t state;

    // ---------------- tick: provided clock_divider + one_pulse ----------------
    // clk_div falls (1 -> 0) once every 2^T0 cycles; one_pulse turns that into a 1-cycle tick.
    logic cd, t25, step;
    clock_divider #(.n(T0)) u_cd (.clk(clk), .clk_div(cd));
    one_pulse u_tick (.clk(clk), .pb_in(~cd), .pb_out(t25));
    assign step = (state == S_START) && t25;

    // ---------------- racers ----------------
    // dir = 1 : LEFT  (toward LD15, index + 1)   dir = 0 : RIGHT (toward LD0, index - 1)
    // 4-bit arithmetic wraps automatically: 15 + 1 = 0, 0 - 1 = 15
    logic [3:0] m1, m2;
    logic       d1, d2;
    logic [4:0] hits;           // number of racer-racer collisions (0..15)

    logic [3:0] n1, n2, b1, b2; // next (forward) and back positions
    assign n1 = d1 ? m1 + 4'd1 : m1 - 4'd1;
    assign n2 = d2 ? m2 + 4'd1 : m2 - 4'd1;
    assign b1 = d1 ? m1 - 4'd1 : m1 + 4'd1;
    assign b2 = d2 ? m2 - 4'd1 : m2 + 4'd1;

    // a racer is blocked by a wall, by the other racer, or when both
    // would step onto the same LED
    logic racer_col, blk1, blk2;
    assign racer_col = (n1 == m2) || (n2 == m1) || (n1 == n2);
    assign blk1 = sw[n1] || (n1 == m2) || (n1 == n2);
    assign blk2 = sw[n2] || (n2 == m1) || (n1 == n2);

    always_ff @(posedge clk) begin
        if (rst) begin
            state <= S_RESET;
            m1 <= 4'd1;  d1 <= 1'b1;    // Mr.1 at LED1, LEFT
            m2 <= 4'd10; d2 <= 1'b0;    // Mr.2 at LED10, RIGHT
            hits <= '0;
        end else begin
            case (state)
                S_RESET: if (start_p) state <= S_START;

                S_START: begin
                    if (start_p || hits == 5'd15) state <= S_PAUSE;

                    if (step) begin
                        // Mr.1: bounce = reverse and move the other way (stay if stuck)
                        if (blk1) begin
                            d1 <= ~d1;
                            if (!sw[b1] && b1 != m2) m1 <= b1;
                        end else m1 <= n1;
                        // Mr.2
                        if (blk2) begin
                            d2 <= ~d2;
                            if (!sw[b2] && b2 != m1) m2 <= b2;
                        end else m2 <= n2;

                        if (racer_col && hits != 5'd15) hits <= hits + 5'd1;
                    end
                end

                default: // S_PAUSE: resume only if fewer than 15 collisions
                    if (start_p && hits != 5'd15) state <= S_START;
            endcase
        end
    end

    // ---------------- outputs ----------------
    assign led = sw | (16'b1 << m1) | (16'b1 << m2);

    // codes for SevenSegment: 0-9 digits (5 = 'S'), 10 = r, 11 = P, 12 = blank
    localparam logic [3:0] CH_R = 4'd10, CH_P = 4'd11, BLANK = 4'd12;
    logic [3:0] letter;
    always_comb begin
        case (state)
            S_RESET: letter = CH_R;
            S_START: letter = 4'd5;      // "S"
            default: letter = CH_P;
        endcase
    end

    logic [15:0] nums;
    assign nums = {letter, BLANK,
                   (hits >= 5'd10) ? 4'd1 : 4'd0,                       // tens
                   (hits >= 5'd10) ? 4'(hits - 5'd10) : hits[3:0]};     // ones

    SevenSegment u_seg (.display(DISPLAY), .digit(DIGIT), .nums(nums), .rst(rst), .clk(clk));
endmodule

// ===================================================================
// Provided modules (given in the exam: clock_divider, debounce, one_pulse,
// SevenSegment). Pasted unchanged, except: SevenSegment got codes 10 (r), 11 (P), 12 (blank).
// ===================================================================
module clock_divider #(
    parameter n = 27 // 2^27 / 100M Hz = 1.34s
)(
    input logic  clk,
    output logic clk_div  
);

    logic [n-1:0] num;
    logic [n-1:0] next_num;

    always_ff @(posedge clk) begin
        num <= next_num;
    end

    assign next_num = num + 1'b1;
    assign clk_div = num[n-1];
endmodule


module debounce #(
    parameter n = 8
)(
    input logic clk,
    input logic pb,
    output logic pb_debounced
);

    logic [n-1:0] shift_reg;

    always_ff @(posedge clk) begin
        shift_reg[n-1:1] <= shift_reg[n-2:0];
        shift_reg[0] <= pb;
    end

    assign pb_debounced = &shift_reg;
endmodule


module one_pulse (
    input logic clk,
    input logic pb_in,
    output logic pb_out
);

	logic pb_in_delay;

	always_ff @(posedge clk) begin
		pb_out <= (pb_in & ~pb_in_delay);
		pb_in_delay <= pb_in;
	end
endmodule


module SevenSegment(
	output logic [6:0] display,
	output logic [3:0] digit,
	input logic [15:0] nums,
	input logic rst,
	input logic clk
);
    
    logic [15:0] clk_divider;
    logic [3:0] display_num;
    
    always_ff @(posedge clk or posedge rst) begin
    	if (rst) begin
    		clk_divider <= 16'd0;
    	end else begin
    		clk_divider <= clk_divider + 16'd1;
    	end
    end
    
    always_ff @(posedge clk_divider[15] or posedge rst) begin
    	if (rst) begin
    		display_num <= 4'b0000;
    		digit <= 4'b1111;
    	end else begin
    		case (digit)
    			4'b1110 : begin
					display_num <= nums[7:4];
					digit <= 4'b1101;
    			end
    			4'b1101 : begin
					display_num <= nums[11:8];
					digit <= 4'b1011;
				end
    			4'b1011 : begin
					display_num <= nums[15:12];
					digit <= 4'b0111;
				end
    			4'b0111 : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end
    			default : begin
					display_num <= nums[3:0];
					digit <= 4'b1110;
				end				
    		endcase
    	end
    end
    
    always_comb begin
    	case (display_num)
    		4'd0: display = 7'b1000000;
            4'd1: display = 7'b1111001;
            4'd2: display = 7'b0100100;
            4'd3: display = 7'b0110000;
            4'd4: display = 7'b0011001;
            4'd5: display = 7'b0010010;
            4'd6: display = 7'b0000010;
            4'd7: display = 7'b1111000;
            4'd8: display = 7'b0000000;
            4'd9: display = 7'b0010000;
            4'd10: display = 7'b0101111;   // r  <- added for this problem
            4'd11: display = 7'b0001100;   // P  <- added for this problem
            4'd12: display = 7'b1111111;   // blank  <- added for this problem
			default : display = 7'b1111111;
    	endcase
    end
endmodule
