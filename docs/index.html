考試長這樣

根據 2021、2022、2023 三年的期中考，題型固定是三題，兩小時（15:30–17:30），寫完上傳到 OJ。

30%

A · 模擬題

同步 ALU：依 ctrl 做四種有號運算，輸出前加一級 flip-flop。用助教的 testbench + pattern 檔驗證。

30%

B · 模擬題

照規則運作的循序電路：奇怪的計數器、Hamming 解碼……今年可能出 Lab 5 的記憶體題。

40%

C · FPGA 實作

在 Basys3 上做 LED 小遊戲：FSM + 按鈕 + 開關 + LED + 七段顯示器，必須能產生 bitstream。

會被扣分的規則（每年都一樣）
  • 模組名稱必須是 exam1_A、exam1_B、exam1_C，I/O 不能改。
  • 每個檔案第一行是註解：// 學號 姓名，漏了扣 5 分。
  • 不能改 testbench、pattern、XDC。助教會用同一個 testbench、不同 pattern 重測，所以不能「對答案寫死」。
  • C 題所有用到的模組（除彈跳、七段顯示…）都要放在同一個檔案，而且要能合成出 bit 檔，不然 C 題 0 分。
  • B 題常禁止 lookup table、寫死數列；有時禁止 / 或 %（用了只拿一半）。

今年改用 SystemVerilog，差在哪？

舊考題的範本是 Verilog（.v，用 reg/wire、always @(posedge clk)）。今年的 Lab 全部是 .sv，所以考試範本很可能長這樣：

舊（Verilog）

module exam1_A(
    input wire clk,
    input wire rst,
    input wire [7:0] A,
    output reg [15:0] out
);
    always @(posedge clk) begin
        if (rst) out <= 0;
        else     out <= A;
    end
endmodule

新（SystemVerilog）

module exam1_A (
    input  logic       clk,
    input  logic       rst,
    input  logic [7:0] A,
    output logic [15:0] out
);
    always_ff @(posedge clk) begin
        if (rst) out <= '0;
        else     out <= A;
    end
endmodule

邏輯完全一樣，只是寫法更嚴格、更不容易寫錯。完整對照表在 SystemVerilog 語法 → Verilog 對照。另外，Lab 5 的記憶體（RAM、valid bit、write-first）是舊考古題沒有的新範圍，模擬考 B 題特別練這個。

讀書路線

  1. SystemVerilog 語法：logic、位元寬度、有號數、always_comb / always_ff、阻塞與非阻塞。A 題的分數幾乎都死在有號數。
  2. 設計模式：FSM 三段式、計數器與 tick、按鈕去彈跳、LFSR、記憶體、不用 / % 的數學技巧。
  3. 模擬與 Testbench：看懂助教的 testbench 為什麼要求「晚一拍」輸出，怎麼加 pattern 檔。
  4. FPGA 實作：Basys3 腳位、七段顯示器掃描、C 題的標準架構、Vivado 流程與常見錯誤。
  5. Lab 1–5 回顧：每個 practice 的重點與解答，這些就是考題的零件。
  6. 歷屆考題：2021–2023 共 9 題，逐題拆解思路、完整解答、易錯點。
  7. 模擬考：三題新題目 + testbench，限時兩小時自己寫；另有觀念測驗。
  8. 考場速查：考前最後一天只看這頁。

考古題一覽

年份A（30%）同步 ALUB（30%）循序電路C（40%）FPGA
2021A*B、{A&B, A|B}、A>>>3、A-B規則計數器：上數到 183921，再下數到 0兩個 LED 賽跑者，撞牆/互撞反彈、計次
2022A*(-B)、xor/nor 串接、A+B、比大小類費氏計數器，禁用 /、%AI 與玩家搶旗子，玩家可變大小變速
2023A*B+3、and/xor 串接、(A+B)<<2、不用 / 比較 A/4Hamming(12,8) 單錯更正 + 小 ALU兩條蛇吃蘋果，計時 10 秒、分差 3 結束

規律：A 題每年都是「有號數 + 位元寬度 + 一級暫存器」；B 題是「把文字規則翻成狀態與計數器」；C 題是「FSM + 多種速度的 tick + 按鈕 + LED 位置 + 七段顯示」。

兩小時怎麼分配

時間做什麼
0–5 分三題都掃一遍，填好每個檔案第一行的學號姓名。
5–30 分A 題：最快拿分。寫完立刻模擬，PASS 就上傳。
30–65 分B 題：先在紙上算前 5 個值，確認懂規則再寫。上傳。
65–115 分C 題：先讓 RESET 狀態 + LED + 七段顯示正確（部分分數），燒進板子確認；再一個功能一個功能加。每加一項就重新產生 bitstream 並上傳一次。
最後 5 分確認三個檔案都上傳成功、模組名稱正確。
策略C 題的評分是一項一項給的（RESET 5%、移動 10%…）。能合成、部分正確遠比「全部寫完但合成失敗」好。合成一次要幾分鐘，所以早點開始跑。
